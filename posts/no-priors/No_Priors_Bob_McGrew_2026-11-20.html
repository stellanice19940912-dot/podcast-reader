一句话概述

《No Priors》中，埃拉德·吉尔与莎拉·郭对话阿尔达（Arda）首席执行官兼联合创始人、前 OpenAI 首席研究官、帕兰蒂尔早期高管鲍勃·麦格鲁。他认为自动化研究员不会带来硬起飞，超级智能必须进入物理世界；阿尔达正与安杜里尔合作，目标是让自动线能在七天内换产。

核心要点

  • 鲍勃认为「把研究员自动化就会硬起飞、出现奇点」是错的：二〇二四年他在 OpenAI 任首席研究官时，瓶颈是 GPU 等物理算力而非人数；自动化研究像从 GPT-4o 走到 o3 那样是一次性 S 曲线，最多把 GPU 发现效率从约百分之三十五推到约百分之九十，不会启动自我改进循环。
  • 智能变便宜后，稀缺的是湿实验室、许可与施工等互补品。他用缺推土机却要先建推土机工厂、建厂又需要更多推土机的思想实验说明：即便模拟把实验减到原来的十分之一，数字红利也会被很快吃掉，然后再次卡在物理世界。
  • 美国擅长设计、弱于制造，根因是劳动力成本。每年 iPhone 约百分之七十五零件更换，只有约百分之二十五走高自动线；汽车可花约两亿美元、七年摊销，账才算得过来。亚洲约一百万人装配、约一万名制造工程师。阿尔达的目标是把设计上传到云端，在七天内重构自动线，首先服务国防、消费电子和数据中心供应链。
  • 不必上人形：许多工位一两只手臂加摄像头就够。现有自动化已能覆盖约百分之九十（线束仍难），障碍是专机每年重建的经济性。装配线是封闭世界，传统方案像鲁布·戈德堡装置，一半在设计、一半在校准；封闭世界要求约百分之九十九点九的成功率。
  • 与安杜里尔合作约一年：一月接入系统，四月首位用户把作动器虚拟装配从几天做到九十分钟，现已覆盖无人机、导弹并进入 Fury 协同作战飞机。他们先为制造工程师补上相当于 Cursor / Git 的环境，用前沿模型当编排器，不自训大模型；部署上坚持帕兰蒂尔式前线部署工程，强调产品化而非派顾问。
  • 终点图景是感知与行动的繁荣，而不只是人形机器人；工厂将以更智能的方式建造工厂。他认为近乎光速扩散的自我复制机器，可能是费米悖论的一种解法——文明波到达前几分钟或几年你才能看见——并希望人类成为那道波，且尽量保持控制。

  1. 1开场：数字世界变了，物理世界几乎没变查看原文 →

    片头里，阿尔达（Arda）首席执行官兼联合创始人鲍勃·麦格鲁（Bob McGrew）说：看看窗外，和十年前人工智能出现之前相比几乎没有不同；第一次坐 Waymo 会觉得神奇，第三次就只剩对旧金山堵车的抱怨。莎拉·郭介绍他曾是帕兰蒂尔（Palantir）早期核心高管、后任 OpenAI 首席研究官。埃拉德·吉尔问：在递归自我改进（RSI）、研究员可能被代码取代的当口，为什么还要做物理世界？鲍勃的回答是：ChatGPT 和智能体带来的进步几乎都发生在数字生活里，对「原子」影响很小。Waymo 只算走到物理世界的半途——车不会飞，九十年代就让旧金山车程变慢的那些物理障碍一块都没消失。他认为，物理世界不发生变化，就到不了超级智能。

  2. 2自动化研究员不会带来硬起飞查看原文 →

    鲍勃说，大约从二〇一八年起就有一种常见论证：把研究员工作自动化，就会释放失控的自我改进循环，出现奇点，也就是莎拉所说的「硬起飞」。他称这是直截了当地错了。对方的算法是：自动化百分之十有一点改进，百分之五十快一倍，百分之九十快十倍，百分之九十九快一百倍。错在研究员并不是瓶颈。发现所需时间主要不取决于人数，而取决于实验。二〇二四年他在 OpenAI 任首席研究官时，限制因素是手头的 GPU 以及算力是否部署、联网得当，而不是能招到多少人。自动化研究影响可以很大，他甚至把它比作从没有推理的 GPT-4o 走到带推理和工具的 o3 那种一次性加速，但它不是递归自我改进。更恰当的模型是：现在 GPU 大约只发挥到最优发现效率的百分之三十五，自动化也许能推到百分之九十；从百分之九十再到百分之九十九差别不大。这是又一条 S 曲线，不是自我改进循环。

  3. 3智能变便宜后，稀缺的是湿实验室和工厂查看原文 →

    埃拉德问：在机器人、生物这类以物理世界为主要限制的市场里，进步会汇聚到 Anthropic、OpenAI、谷歌及同构实验室（Isomorphic）这类子公司，还是会由一批创业公司推动？鲍勃先不谈市场结构，而谈经济结构：实验室真正在生产的是便宜的智能；选择实验、提出假说，是湿实验室和铺开 GPU 这一物理层的互补品。假说越便宜，就越会更猛地撞上有限的湿实验室。他认为 Anthropic、OpenAI 在建设湿实验室上大概没有比较优势。离开 OpenAI 时，他唯一确定的是不想再开一家前沿实验室，甚至想成为「离开 OpenAI 却不去开新实验室」的那个人。抓住他的问题是：模型已经很强，对世界的改变却没有那么大。莎拉补充：硅谷爱谈的「丰裕」本身就是一个物理词，指的是食物、住房或家庭，而不是数字工作的丰裕。

  4. 4推土机悖论：数字加速终会再撞上物理世界查看原文 →

    鲍勃用 O 型环生产函数说明：所有环节都得做成。加快纯数字的住房流程并不重要，难的是许可证和施工，多少智能体都帮不上忙。针对「足够聪明的智能体几年内就能造出戴森球」，他做了思想实验：缺推土机就去建推土机工厂，可建厂第一步是平整土地，平整土地又需要更多推土机。埃拉德提出两类物理问题：必须真去建造的，以及能用足够好的模拟（如蛋白质折叠）把湿实验减到最少的。鲍勃认为体感会一样，因为数字世界极快。即使预测好了十倍、实验只需原来的十分之一，这段数字红利会被很快吃掉，然后再次卡在物理世界。他回忆在 OpenAI，首席科学家伊利亚听完论文后总问「那结果呢」：深度学习看似纯数学，其实是实验科学，判断想法好不好最终还得做实验。

  5. 5阿尔达要解决的问题：让自动线能在七天内换产查看原文 →

    离开 OpenAI 后，鲍勃花一年拜访制造业负责人，结论是美国擅长设计、弱于制造，根因是劳动力成本。iPhone「加州设计、中国制造」就印在机身背面。不做国防、又想在美国有成本竞争力，就必须上自动线；但创新产品本身会变：每年的 iPhone 约百分之七十五零件更换，只有约百分之二十五走高自动化产线，其余靠手工，因为今天的自动化像只解决一个物理问题的定制机器，甚至无法从一代 iPhone 泛化到下一代。造汽车可以花两三年、约两亿美元建高度自动化工厂，再以七年时间生产同一车型、只做外观小改，账算得过来；若要把自动化比例从约百分之二十五提到约百分之九十才适合 iPhone，专机每年重建的成本摊销不掉，除非自动化更灵活。亚洲约有一百万人装配 iPhone 或部件，对应约一万名制造工程师负责立线、停线。工人可在一天内再培训；制造商哪怕在人工线上，能在七天内把设计变更送进生产，就会觉得自己非常敏捷。阿尔达的目标是：把产品设计上传到云端，在七天内设计并最终重构一条自动线。最需要这种高混线、快速换产的是国防（乌克兰战场变化只需数周就要变成实物改动再推回前线）、消费电子，以及芯片频繁迭代的数据中心供应链——这些领域因此几乎仍靠手工。

  6. 6不必人形：封闭世界、鲁布·戈德堡装置与校准查看原文 →

    形态上「以上都有」，但最明显的是可重构机器人工位，让设计变更立刻变成工厂里的实际变化。埃拉德提出两种理论：产线为人设计，所以最自然的是人形；或者把现在因周转快而用手做的工序，做成汽车焊接臂那样的分步流程。鲍勃说他们要替代的是人，不必进入汽车那种庞大繁复的机器人体系：两只手臂加摄像头往往就够，很多工位一只手臂就够，并不需要人形。现有自动线已能覆盖所讨论产品中大约百分之九十（线束仍很难），iPhone 自动化的障碍不是灵敏度——那种精度已经有了——而是经济性：这些资本支出每年都要重新设计和重建。开放世界（如从没进过、也不会再去的卧室清洁）接近人类智能、长程规划很难；装配线是封闭世界，传统方案像鲁布·戈德堡装置：滑槽、振动杯、夹具精确定位，机械臂甚至不需要感知就能从坐标移到坐标。周转要花约六个月，是因为一半在设计机器，一半在校准；螺母偏十分之一毫米，就可能对不齐。引入感知、强化学习和操作后，校准不必那么极端，可从简单工位做起再进入套密封圈这类古怪工序。但封闭世界要求约百分之九十九、甚至百分之九十九点九的次数都必须把器件真正做成，和卧室里漏掉几样东西没关系不同。

  7. 7与安杜里尔一年：先做制造工程师的 Cursor，问题优先查看原文 →

    过去一年阿尔达与国防制造商安杜里尔（Anduril）合作，搭建让制造工程师能设计产线的软件和人工智能平台。对方很多产品产量还撑不起传统自动线。公司注册前一天双方就开始谈；他们要的北极星是制造工程的单一事实来源，以及可按需求开、停线的可重构工厂。一月份接入系统，四月份第一位用户把一只作动器的虚拟装配从通常几天缩短到九十分钟。此后已部署到对方所有产品事业部，覆盖无人机、导弹，并在把 Fury 协同作战飞机的整套制造过程变得对人工智能可读，不再散落在一百个地方的一百份文件里。制造工程师没有现成的集成开发环境，所以他们先做出相当于 Cursor / Git 的数据结构，再叠上智能体，并向左给出面向制造的设计反馈、向右设计自动工位。方法来自帕兰蒂尔的问题优先、前线部署；这和 OpenAI 相反——伊利亚在 GPT-3 时期就拒绝「先服务好一个客户再扩展」，因为把训练数据扩大十倍能学到的更多。阿尔达因此不自训前沿大模型：理解工艺、设计产线是前沿模型已能做的；进入机器人后，前沿模型更适合当编排器，去调度他们自建的运动规划、CAD 检查等专用工具。鲍勃认为，若要最智能的模型，最终只会有少数资本密集的巨大模型；但非前沿实验室去做小的专用模型，至少目前仍可接近、甚至局部更好，训练这样一个模型和写一个工具是同一类动作。

  8. 8从帕兰蒂尔到 OpenAI：跳棋、魔方和不再相信的机器手查看原文 →

    埃拉德问他如何从务实的帕兰蒂尔，走进二〇一八、二〇一九年还在用游戏和几条闲置机械臂做宽基研究的 OpenAI。鲍勃把故事推到二〇〇二年至二〇〇五年在斯坦福人工智能实验室读博时期：课题组当时还在嘲笑相信神经网络会奏效的人，因为没有像支持向量机或回归那样可证明的保证。他正是因为觉得人工智能没有真正发生，才在二〇〇五年辍学加入帕兰蒂尔，并在那里做了十年工程和产品。大约二〇一五年，AlexNet 已过去几年，视觉模型开始真正管用。他以为机器人会是这些模型的用武之地，结果错了：花一年半自学安德烈·卡帕西的深度学习课程，做到让机器人根据视觉下跳棋后，他判断「太难了，还不是创业的时机」，于是加入一家以打造通用人工智能为目标的非营利组织，预期只待几年，向伊利亚、沃伊切赫·扎伦巴、卡帕西等人学习。他加入机器人团队，目标是用酷的进展证明深度学习值得认真对待。扎伦巴在会议上问同行什么会让他们觉得不可思议，答案落到用 Shadow Hand 解魔方；他们做了两年并且做成了。但这段经历让鲍勃说自己「永久不再相信机器手」，尽管他听说工程已经变好。

  9. 9Astra 与 Fable：表征、微调，以及端侧必须要快查看原文 →

    莎拉问：Astra、Fable 已能从通用模型生成在真实世界做事的策略，这是否意味着人们不必再专门为通用机器人训练模型？鲍勃说会不会停，大概取决于风险投资；能成立是因为苦涩的教训，但机器人一直缺数据。靠巨型遥操作实验室，或用 UMI 这类筷子状装置把采集成本降到约十分之一，仍是极端稀缺的来源。若训练 GPT-4 全靠向 Scale AI 买人工书写数据，根本训练不出来。关键不是在部署任务上从零训模型，而是先得到对世界很好的表征再微调；表征来自预测真实世界数据（可以是互联网视频）里最后那几位有效比特。他怀疑 Astra、Fable 里机器人数据相对总体仍然很少，是模型进步后终于挤出了已有物理数据的最后几比特。他用「GPT-4 会调试」被当成涌现、其实杰瑞在这上面做了约两年为例，说明能力往往没有看起来那么涌现。进步引擎不是谁多采了机器人数据，而是模型摸到了已有物理数据的最后几比特。这会把领域民主化，但也有张力：数字任务少样本很强，机器人则几乎都需要微调；Astra、Fable 开箱强但慢，且很难针对场景微调，这给了 Pi、General 用数据做专用微调的机会。智能体式机器人把这些模型当成众多工具之一：封闭世界里只有极需灵巧的步骤才值得放上又慢的 Fable。埃拉德补充开放世界不能忍受网络延迟，智能要尽量长在设备上。鲍勃同意，既是安全也是速度：机器人要非常快的时钟周期，历史上靠蒸馏到小模型解决，例如 Astra 变成仍能覆盖常见用例、但跑得很快的 Luna；端侧模型也会很重要，并往往依赖开源再吸收大实验室的数据。

  10. 10前线部署工程：超级用户、产品化，而不是顾问查看原文 →

    面对「和大型在位者改物理流程会很慢」的常规看法，鲍勃说第一方技术和为大型企业做产品完全不是一回事，阿尔达用的是前线部署工程（FDE）。这套方法早在二〇〇五年就在帕兰蒂尔成形：他曾在北弗吉尼亚的安全空间里，为工作流不能带出大楼的人做产品，这成了为任何有商业秘密的企业做产品的训练。他将最大功劳归给现任首席技术官希亚姆·桑卡尔，自己则负责想清楚如何为它做产品：工程师嵌入客户身边，没有准备使用的客户就不做该功能；路线图的起点是「先找到需要这个功能的客户」。要快，先找少数超级用户——当年机构里的莎拉·亚当斯大约有一年几乎是帕兰蒂尔唯一用户，东西不好用就去修，好用了才有更多人跟上。阿尔达在安杜里尔的第一位用户是一位做作动器虚拟装配的首席制造工程师，过程极其挫败，但产品负责人就坐在旁边做记录，两周后问题就能用。六个月后要帮导弹团队加快生产，新产零件数大约是最初那只作动器的一百倍、多两个数量级，开箱再次不好用，必须再找到那位超级用户一起打磨。《跨越鸿沟》强调早期要有愿景型赞助者，但鲍勃补了一句：还需要一个真正用软件去达成结果的用户。大组织只是小团队的集合，OpenAI 并不「想要」什么，是萨姆、格雷格或某个研究科学家想要某件事。FDE 不是把软件扔过墙，而是合伙达成「把导弹造得更快」这样的结果，从而赢得去做 Fury、或去做以美元计更能推动针的更大问题的权利。二〇一五到二〇二〇年这套方法曾被嘲讽为「不过是顾问、没有杠杆」；直到帕兰蒂尔成为市值约三千亿美元的公司并开始盈利，才有人跟风。关键差别是：前线工程师填的是产品与用户之间的空隙，必须把看到的东西产品化、烘焙回产品，否则就得不到杠杆。

  11. 11超级智能的物理后果：工厂建造工厂，机器走向星辰查看原文 →

    被问到终点愿景时，鲍勃回到超级智能。他喜欢达里奥「数据中心里的天才之国」的说法，但若他们只能坐在里面收发邮件，就做不了多少事，他们被困住了。智能变便宜后，互补品是感知和行动；现在为数据中心里的智能充当眼和手的是人类。他预期未来十年会有各种感知与操作的繁荣：无人机、人行道机器人，每件物理之物都会带上感知、接到云上并由人工智能控制。那不会只是一支人形机器人大军，而会像各种动物：会飞的、四条腿的、负重的、犁地的（拖拉机已经是了）。超级智能不应只住在数据中心里盘算如何接管世界，而应走出来帮人做事，这正是制造的行动号召。埃拉德提起冯·诺依曼探测器式的自我复制与指数扩散，问地球上最终会不会出现自我复制的工厂。鲍勃说，要更多推土机就得建推土机工厂，这里已经有递归循环；工厂建造工厂很快会出现，本质上就是更智能的机床，建厂和设计机床的大量人类劳动必须被自动化，才能支撑巨大的物的网络。这不是数字奇点「对」物理奇点，而是并肩：数字奇点的一部分，就是把越来越大比例的地壳变成数据中心，也许还会到太空，这一物理过程得由人工智能指引，如同人类文明的扩展曾由人类智能指引，他认为这是未来十年就会发生的近景。更长远，能自我复制的机器比人类更适合在星辰间扩散，几乎注定会发生；必须确保它解放人类、让人类受益并尽量保持控制，而不是人类留在地球上看人工智能生成的视频。

自动化研究员不会带来硬起飞

↑ 返回总结
埃拉德

你说没有物理世界的改变就无法拥有超级智能，这到底是什么意思？具体会落实成什么？

鲍勃

不妨从一种常见看法说起。大概从二〇一八年起我就一直听到这个论证：只要能把研究员的工作自动化，就能释放出失控的加速、失控的自我改进循环，然后就会出现奇点。

莎拉

也就是硬起飞。

鲍勃

对，硬起飞。我正是这个意思。而我认为这个论证是错的，而且是直截了当地错了。它的逻辑是这样的：你先自动化研究员百分之十的时间，会有一些改进；自动化百分之五十，就有两倍提升，进度快一倍；自动化百分之九十，快十倍；自动化百分之九十九，快一百倍。于是靠不断取消研究员的劳动，你就能一路冲上去，出现失控加速。

这之所以错，是因为研究员并不是瓶颈。发现一样东西所需的时间，主要并不取决于你有多少研究员。这些研究员本质上是在做实验。就连两年前、二〇二四年我还在 OpenAI 担任首席研究官时，真正的限制因素也不是能招到多少研究员，而是手头有多少块 GPU，是我们能部署出去的物理算力：算力是否积累在该在的位置，网络是否把它们正确地连在一起。

你当然可以把研究员完全自动化，这影响很大，我并不是说这不重要。自动化研究的能力，其冲击力或许甚至比得上从没有推理的 GPT-4o，走到带推理和工具的 o3——那是一次巨大的一次性加速，但它不是递归自我改进。正确的心智模型是：研究就是要跑一批实验。现在浪费很多，研究员要做大量工程，要选对实验，还要亲自去 GPU 上排期，这些都会让 GPU 在产出新发现上变低效。

所以你应该看着 GPU 说：好，现在这些 GPU 大概只发挥到最优发现效率的百分之三十五；如果能自动化得更多，也许能推到百分之九十。但从百分之九十再走到百分之九十九，差别其实不大。我们可以自动化研究员，这是一次巨大的一次性收益，却不会启动自我改进循环。它只是又一条 S 曲线，又一次类似推理那样的大幅一次性改进，让我们更接近最优，然后必须去做下一件事。

智能变便宜后，稀缺的是湿实验室和工厂

埃拉德

我感觉很多人工智能驱动的研究，或者说整个人工智能发展，基本上就是在叠不同类型的 S 曲线。这在其他领域也会出现。机器人、生物，还有一些地方，物理世界才是进步的主要限制：你必须做生物实验，必须造出机械手用的电机。在这些既有很强研究成分、又必须并行克服或优化物理限制的大市场里，你怎么看实验室会推动的进步，和创业公司会推动的进步？机器人、生物会不会都汇聚到 Anthropic、OpenAI、谷歌以及它们像同构实验室（Isomorphic）这样的子公司手里，还是会有一批创业公司来推动这些进展？

再回到市场结构，两种可能都有。但 Anthropic、OpenAI 在建设湿实验室上有比较优势吗？我认为大概没有。

推土机悖论：数字加速终会再撞上物理世界

鲍勃

对。而且要把一件事真正做完，经济学里有时叫 O 型环生产函数：所有环节都得做成。如果我们只是加快纯数字的住房建设流程，其实没那么重要。盖房子真正难的是拿许可证，多少智能体都帮不上忙；你还得做施工本身。

我有一个关于超级智能影响的心智模型。有人会说：只要智能体足够聪明，几年内就能造出戴森球。做一个思想实验：假设我们卡在建数据中心，想建很多，但速度很慢。缺推土机？没问题，人工智能知道该怎么做，它会去建一座推土机工厂，这样就能造更多推土机。可建推土机工厂的第一步是什么？先平整土地。平整土地又需要什么？更多推土机。

埃拉德

这点很有意思。建造上我完全理解你的观点。但我在想，在生物、化学、材料这些领域，如果你能建立足够强的内部模型，把很多事情模拟得足够好，会不会不一样？蛋白质折叠就是很好的例子：你不必再去解那么多晶体结构，不必再做那个实验，因为计算机里的预测已经足够好。也许物理世界的问题要分成两类：一类是你必须真的去造推土机，或先造出能制造下一层制造能力的制造能力；另一类是你可以把实验模拟到不再需要湿实验室，或把湿实验室、材料架、物理实验室里必须做的事减到最少。所以这些问题并不完全一样，我们面对的是两类不同的物理世界问题。

鲍勃

这很有意思，但我觉得它们体感会一样。原因是：数字世界里我们能做的任何事都会极快。以湿实验室为例。假设我们做出了非常出色的蛋白质及其在细胞中相互作用的数字模拟，对实验会发生什么的预测一下子好了十倍，于是要做出一项发现，只需跑原来十分之一的实验。在那段时间里，我们会暂时卡在数字世界而不是物理世界。可我们在数字世界里移动得非常快，会很快把这次加速吃掉。这和其他事情类似，是一次一次性加速，然后我们又会重新卡在物理世界。那时预测已经好了十倍，但那些实验还是得跑。

我记得在 OpenAI 的一个类比。我是首席研究官，伊利亚（Ilya）是首席科学家。尤其早期，我会读到一些论文，觉得这些方法太酷了，跑去跟伊利亚讲：他们有这个想法，是这样运作的。伊利亚会耐心听我讲完，最后问：「那结果呢？」因为即便是伊利亚也知道：想法可以很酷，可能行也可能不行，到头来你必须做实验。

深度学习没有物理实体，在某种意义上像纯心智、纯数学的科学，但它其实是实验科学。伊利亚可以告诉你：这是坏主意，连试都不用试。可还有大量其实很好的想法。只是投入更多智能去判断「这是不是好主意、会不会有帮助」，是不够的，你必须去做实验。也许我们能找到代理指标，那很好；找到之后就扩展开来完成它，然后我们又会猛烈地撞上物理世界。

埃拉德

那具体谈谈阿尔达在做什么。你们怎样进入物理世界？目前聚焦哪些产品或方向？

鲍勃

先从我们要解决的问题说起。离开 OpenAI 之后，我注意到：美国非常擅长设计产品。iPhone 就很有名，加州设计、中国制造，这句话就印在你的 iPhone 背面。我们在国防物资的设计上也非常强，但在这里制造得并不多。于是我花了一年时间拜访制造业负责人，问他们到底是怎么回事。从根本上说，问题落在劳动力成本上。

若想在美国把东西造出来，一种可能是做国防：你可以按自己的方式定价，只要能用，政府就会买，这很好。但如果你不在国防领域，想在美国有成本竞争力，就需要建自动化产线。我们在设计各种创新产品，而创新产品的一部分就是产品本身会变。众所周知，每年的 iPhone 大约有百分之七十五的零件会更换，只有约百分之二十五保持不变。那百分之二十五走的是高度自动化产线，另外百分之七十五靠手工装配。

原因是：你若想建能完成这种装配的自动化，这种自动化会非常专用。我们今天做自动化的方式，就像一台只解决某一个物理问题的定制机器，它既不能从一部手机泛化到另一部，甚至不能从一代 iPhone 泛化到下一代。

再看美国能造什么。如果你在造汽车，很好：花上两三年、大约两亿美元，建一座高度自动化工厂，然后用七年时间生产同一款车、只做小的外观更新，经济账完全说得通。可如果要把这套用到 iPhone 上，首先自动化比例得从大约百分之二十五提高到大约百分之九十，账才能算过来。然后你又该如何替换掉那一整套自动化？那是一笔极其巨大的成本，除非自动化变得更灵活，否则你摊销不掉。

还有第二层：这些自动化到底由谁来设计？在亚洲，大约有一百万人在装配 iPhone 或相关部件；与之配套的，大约有一万名制造工程师，负责搞清楚该用什么工艺、如何把装配线立起来，以及到了要上一代新产品时，如何把旧线停下来。这就是我们真正想解决的问题：怎样让一条自动线的切换，能像在人工工厂里改训工人一样容易？

工人可以在一天内重新培训。实际操作里，制造商哪怕是在人工线上，只要能在七天内把一项设计变更送进生产，就会觉得自己已经非常敏捷。我们希望建成这样一套系统：你把产品设计上传到我们的云端，然后在七天内完成自动线的设计，并最终完成重构。

莎拉

先不说人人都希望能按自己的创新节奏、按需尽快做出想要的东西。从商业角度看，哪些类型的产品和客户最需要这种高混线、快速把产线拉起来的能力？因为你刚才也说，汽车可以七年都造同一款。

鲍勃

基本上，就是你在做高度创新、频繁变更的制造，或者方差很大的地方。国防是一个很有意思的例子，作为帕兰蒂尔老兵，这也很贴近我。比如在乌克兰，战场上的变化现在只需要几周，就要变成设计上的物理改动，再被推回战场。时间非常短，驱动它的是乌克兰和俄罗斯之间的竞争压力。

莎拉

因为如果你的对手能比你更快完成这一轮周转。

鲍勃

正是如此。谷歌和苹果之间、安卓生态和 iOS 生态之间，也有竞争压力，只是不那么暴力。当你在做越来越大的市场、越来越创新的产品时，你会希望把创新节奏再拧紧一档。消费电子就是很好的例子。很多进入数据中心的东西也必须频繁改，因为芯片改得很快。国防、消费电子、数据中心及其供应链，就是这类需要快速翻单的行业；也正因为如此，几乎所有东西至今仍靠手工来做。

不必人形：封闭世界、鲁布·戈德堡装置与校准

↑ 返回总结
埃拉德

你说的自动化这些产线，是指人形机器人，还是把现有制造技术重新布置？你怎么看待它最终会采取的形态？

鲍勃

真正的答案是：以上都有。但实际上会是什么样？最明显的一点，是你希望拥有可重构的机器人工位，好让设计变更能立刻流转成工厂里正在发生的实际变化。这是一个难题，显然已经有很多人在做不同的变体。

埃拉德

我问这个，是因为我觉得有两种世界观，而且不一定互相排斥。一种是：现在的制造线等等都是围绕人来设计的，所以最自然的做法就是复制一个人，也就是上人形机器人。另一种看法是：有很多非常常见的制造工序，现在用手做，只是因为如你所说，要快速周转时这样更快；这些工序其实可以做成类似汽车工业里焊接臂那样的分步、顺序流程。你觉得近端和远期，我们分别处在这条光谱的什么位置？

鲍勃

我有两点。先说形态。考虑到我刚才讲的目标，我们要替代的是人，而不是再去替代另一些自动线。我们不必在汽车那种极其庞大、繁复的机器人体系里工作。我认为两只手臂加一个摄像头就够了。很多情况下，其实一只手臂加一个摄像头就够，也许再要更好的传感。从形态上看，这些线上本来就一直站着一个人，你并不需要人形机器人。

埃拉德

那手臂的能力必须大幅改变吗？人们总在谈现有机械臂相对人类的灵敏度和精度。在手臂零部件上，到底还要取得多少进展？还是说硬件其实已经就绪，关键全在软件？

鲍勃

现有的自动线，已经能制造我们谈论的这些产品，至少大约百分之九十。没错，线束装配很难。但如果你去看 iPhone 之类的产品，问自动化的障碍是什么，并不是机械臂没法把每颗螺丝拧够准、没法摆弄每一个细节。那种灵敏度已经存在了。障碍是经济性：这些手臂、这些他们称为资本支出的机器，每年都必须重新设计和重建。

莎拉

它们做得到，只是太贵了。

鲍勃

对，它们做得到，只是按对方想要的节奏来做，太贵了。所以这时你应该从「具身形态」转到「智能层」。在智能层上，我会把机器人问题分成开放世界和封闭世界。如果你要打扫一间卧室，那是开放世界机器人问题：你没见过这里的物品；按我们常想的部署方式，你从未进过这间卧室，以后也不会再来，这是一个非常长程的规划问题，很难，所需的智能很接近人类智能。

封闭世界则是你控制着一切，在非常重复地做同一件事，没有新奇性被引入。装配线就是封闭世界。这说得通，因为我们确实能用相对传统的自动化方法把它们自动化。这些传统方法长什么样，最贴切的类比是鲁布·戈德堡（Rube Goldberg）装置。我曾和十三岁的儿子一起为学校做了一个：球滚下山，碰到铅笔，铅笔再把气球戳破。

用到产线上则变成：有一条滑槽，螺母顺着滑槽下去，下面有一只杯子在振动，螺母因此掉出来，落在夹具上。夹具把它精确定位，于是位置不再有不确定性，机械臂甚至不需要任何感知，就能过来把螺母拿走，再送到同样装在夹具上、同样被精确定位的螺栓那里，把它拧上去。

莎拉

基本上是确定性的。

鲍勃

全是确定性的。

莎拉

从这个坐标移到那个坐标。

鲍勃

对。可这件事难在哪里？为什么周转要花六个月？你要做两件事。第一，你造出了一台机器，得有人去设计它。这不容易，是机械工程，也是制造工程。好在我们现在已经有能设计机器的人工智能，这是加快它的一种办法。

第二件事，是我做鲁布·戈德堡项目时深深体会到的：一半工作在设计，另一半在校准。你得确保球正好打到铅笔，才能把气球戳破。同样，如果螺母偏了十分之一毫米，它可能就到不了夹具上该在的位置，手臂也就没法把它放到器件上正确的地方。

莎拉

这听起来像一个相对简单的强化学习问题，不是吗？

鲍勃

这里恰恰让「智能体式机器人」变得有意思，因为我们不再处于开放世界，而是在一个极度封闭的世界里做一组非常具体的动作。你可以引入感知：螺母稍微偏一点，也不必校准得那么精确，你可以直接去把它捡起来。再引入强化学习和操作，即使螺母在手上的位置不对，你也能处理。器件总是会在夹具里，但你现在是在用真正的操作去把它拧上。

也许你先从更简单的工位自动化开始，再逐步进入那些很古怪的工序，比如要把有弹性的东西撑开、套到密封圈上。还是回到封闭世界：在开放世界里，卧室里漏掉几样东西也许没关系；在封闭世界里，大约百分之九十九、甚至百分之九十九点九的次数，你都必须把那个器件真正做成。

与安杜里尔一年：先做制造工程师的 Cursor，问题优先

↑ 返回总结
莎拉

要造就一名出色的制造工程师，这座山有多高？这个领域有多深？你觉得自己走了多远？

鲍勃

我们的起点是这样的：刚才一直在谈设计自动线，过去一年我们与安杜里尔（Anduril）合作，搭建一个让制造工程师能够设计产线的软件和人工智能平台。安杜里尔是国防制造商，他们并不一定需要自动线，很多产品的产量也还没高到撑得起传统自动线。大约一年前我们走进去——其实在公司注册的前一天就和他们谈过，他们讲了自己的挑战。

他们谈到需要一个制造工程的单一事实来源：有一个地方把制造工艺和制造计划真正封装起来；还需要一座可重构工厂，让你能改工艺，并能按需求把不同产线开起来、停下去。我们把这些当成自动化制造工程的北极星。一月份我们接入了他们的系统，四月份有了第一位用户。他当时要做一只作动器的虚拟装配，通常要花几天，用我们的软件，他九十分钟就做完了。那是我们做的第一件事，为他们省了很多时间，他们也很兴奋。

从那以后，我们已部署到他们所有产品事业部，做过从无人机到导弹的各种工作，目前还在和他们一起做 Fury 协同作战飞机：把整架飞机的制造过程变得对人工智能可读。很多工作，就是把那套制造过程封装起来。它不再散落在一百个地方的一百份文件里，于是人工智能智能体才能真正创造价值。

回到你的问题：怎样才算真正做出一个自动化的制造工程师？幸运的是，我们可以先说：我们想像 Cursor 那样起步。但要注意，Cursor 的做法是在已有的集成开发环境上加一个智能体；制造工程师并没有这样的集成开发环境。所以我们得先把它建出来，要有真正的数据结构，要有相当于 Git 的东西可以操作，然后再把智能体叠上去。

一旦我们以一种特定方式掌控了制造过程，就可以向左向右扩展。你可以说：这个设计是这样制造的；如果想造得更便宜，设计该怎么改？于是我们可以把面向制造的设计反馈送回设计工程——这本来也是制造工程师的职责，但他们可以借助我们的智能体做得更快、更有效。同样，我们也可以向右走：如果要做一个自动化工位，该如何设计一个能完成其中某个制造步骤的自动工位？

埃拉德

这绝对是我见过的、对这个世界最务实的路径。过去这些年迭代很多。我记得大约十年前就投过一些「硬件界的 Git」之类的项目，都碰到如何存储知识、再如何据此行动的问题。真正的解锁，感觉是随着人工智能到来的。你这套方法里还有一点很务实：你们并不试图自建巨型模型，而是问：怎样用相对现成的人工智能，把这件事做得更顺、更快、更省。能不能多谈谈，为什么选择自建模型，或为什么选择用更广泛的现成工具？

鲍勃

我先从简单说起。要解决问题，就该用最简单的工具。再往回退一步：我有过一段帕兰蒂尔的职业生涯，也有过一段 OpenAI 的职业生涯。在帕兰蒂尔，我们极度以问题为中心，想为情报界打造企业平台，最终它成了面向所有企业的企业平台。我们不在乎需要什么技术，也解决过很多很难的技术问题，但用的是前线部署工程方法：听客户要什么，带回到产品里，再无情地扩展，始终盯着问题本身。

在 OpenAI，我们走了相反的路。我们完全不知道这些东西会被用来做什么。我记得有一次和伊利亚聊天，当时刚做出 GPT-3，我们觉得已经不错，但还需要更好。伊利亚问：鲍勃，公司到底该怎么建？要把这做成产品，我们需要做什么？我说，创业圈有一套人人都知道的标准做法：选一个有真实问题的人，真正把他的问题解决掉，再从那里扩出去。伊利亚说：这很有意思。不，这对我们行不通。

我问为什么。他说：跟一个人聊，我们能学到一些东西；但我们有能力把训练数据扩大十倍，那时会从所有人那里学到多得多的东西，远超过从一个客户身上能学到的。这就是为什么有些市场适合技术优先：这套技术有它自己认识世界的方式。而在阿尔达，我们采取的是问题优先。我们为什么不训练模型？我训练过模型，但现在不需要。理解制造过程、据此设计产线，这是我们看到前沿模型已经能做的事。

进入机器人一类事情时，前沿模型也能做一部分，但我们看到它们可能最适合当编排器。制造工程里我们大量在做的就是这件事：我们建了专用算法，用运动规划，还有各种检查 CAD 的工具。并不是前沿模型在贡献全部价值，它们是这些不同工具的编排者。

埃拉德

在软件即服务世界里其实也很常见：用最先进的模型当编排器，再用微调模型或非常专门的模块去做特定应用。有意思的是，这里也出现了同样的结构。

鲍勃

对，我认为这是一种很好的通用思考方式。若你想要最智能的模型，最终只会有少数非常资本密集、非常聪明的模型。除非你在考虑成本，否则我并不认为会有那么多专科模型。但当你不是前沿实验室时，去做一些小的专用模型，至少目前仍可以比现成的前沿模型更好，这件事其实非常可接近。训练这样一个模型，和写一个软件包、写一个工具，在某种程度上是同一类动作。

从帕兰蒂尔到 OpenAI：跳棋、魔方和不再相信的机器手

埃拉德

你是怎么从帕兰蒂尔走到 OpenAI 的？如你所说，你来自一个非常务实的世界。我记得二〇一八、二〇一九年去参观 OpenAI 时，办公室里只有几条没在干什么的机械臂，重点一度放在电子游戏、先在游戏里取胜，后来你们才开始做 Transformer 和 GPT 这条训练路线。在外部观察者看来，有一段时间它是一种非常宽基的研究路径，先多试几样。这对你是一次大的转变吗？为什么要加入一个和你以往习惯如此不同的组织？

鲍勃

答案得再往前推十年。我曾在斯坦福大学人工智能实验室读博士，从二〇〇二年一直到二〇〇五年辍学加入帕兰蒂尔。我还记得和课题组坐在一起，嘲笑那些以为神经网络有朝一日会奏效的人。因为没有证据表明它们会有效，不像支持向量机或回归有清晰可证明的保证；即便有效，你也搞不清为什么有效。既然其他方法明明管用，为什么还要用这些东西？我离开学术界去帕兰蒂尔，正是因为在二〇〇五年，我觉得人工智能并没有真正发生。

我在帕兰蒂尔待了十年，负责工程和产品管理。大约二〇一五年，我环顾四周：AlexNet 已经过去几年，视觉模型开始真正管用，帕兰蒂尔也已大幅成长，我觉得也许该往前走了。我当时想，也许人工智能真的开始奏效了。这些视觉模型会用在哪里？识别照片里的人脸？如果你想做那个，应该去 Facebook 工作，而不是开公司。机器人看起来也许才是那个地方。结果我完全错了。

我花了一年半试图把它做起来，靠看安德烈·卡帕西（Andrej Karpathy）的视频自学深度学习，一直做到能让机器人根据视觉下跳棋。做完之后我意识到：这太难了，还不是创业的合适时机。于是经人介绍，我认识了这一群聪明人组成的非营利组织，他们有一个相当戏剧性的目标：打造通用人工智能。我想，那我就不自己开公司了，先去为一家非营利工作一段时间吧。

我并没想待很多年，预期只待几年，向当时在那儿的伊利亚、沃伊切赫·扎伦巴（Wojciech Zaremba）或安德烈·卡帕西这样的人学习。后来我加入了机器人团队。团队的目标，是用酷的机器人进展，证明深度学习是一件人们应当认真对待的真事，它也许真的会通向通用人工智能。

于是我们选定了一个项目：让一只人形机器手，也就是 Shadow Hand，能够复原魔方。故事是这样的：OpenAI 联合创始人、也是当时机器人团队负责人的沃伊切赫·扎伦巴，在一次机器人会议上四处问人：如果我们做成哪件事，会让你们觉得完全不可思议？人们说：要么是能抓取任意物体的抓放，要么是用机器手做成任何事。那用机器手能做的最震撼的事是什么？不知道，解魔方吧。我们为此做了两年，而且真的做成了。

不过经历过试图让一只机器手做成任何事之后，我现在永久不再相信机器手了。我听说工程已经比那时好了，但我大概这辈子都毁了。

鲍勃

人们会不会停止训练模型，大概取决于风险投资，那更该问你们，而不是我。但为什么这件事现在能成立？是的，这符合苦涩的教训。可机器人领域一直以来的挑战，是你能用的数据量非常小。

于是你会看到有些公司说：我们要用遥操作解决机器人，去建大型遥操作实验室。然后又说：我们可以用 UMI 这类像筷子一样、能记录人操作的小装置，把数据采集成本降到大约十分之一。这些都是极端稀缺的数据来源。我的想法是：如果我们要训练 GPT-4，却得向 Scale AI 付费，让人把全部数据写出来，我们根本不可能真正训练出 GPT-4。

从根本上说，你不必在「恰好要部署的任务」上把模型从零训练好。你需要的是生成对世界很好的表征，再把模型微调到特定问题上。这些世界表征从哪里来？来自预测你所处理的某种真实世界数据里最后那几位有效比特，数据可以是互联网视频。我确信这些模型里其实已经引入了大量机器人数据，但我同样怀疑，在 Astra 或 Fable 这类模型的总体数据里，那一部分比例非常小。

随着模型进步、数据更好、算法改进，模型越来越擅长挤出最后那几比特随机性并做出预测，突然就能预测物理世界里的事件了。一旦有了很好的表征，再把它们对准机器人，机器人便开始奏效。有很长一段时间，人们谈涌现能力。我记得在 Twitter 上看到有人说：看，GPT-4 会调试，能跑程序、看输出、再去修 bug，真是疯狂的涌现能力。我的反应是：杰瑞（Jerry）可是在这上面花了大约两年。它并没有你以为的那么涌现。

我们知道 OpenAI 有机器人团队，Anthropic 也有，他们在做这些事。但我的猜测是：进步的真正引擎，并不是他们比别人多采集了很多机器人数据，而是模型终于能够深入已有物理数据的最后那几比特。

莎拉

你觉得这对整个机器人生态意味着什么？也许这也该问创业者和投资人，但你预期玩家格局会是什么样？人们什么时候会在不同场景里用上机器人？

鲍勃

我认为这会把它民主化。这里有一种我还不知道该如何化解的张力。对数字任务来说，少样本学习非常有效，而且很容易采集到和你实际使用格式相近的数据。在机器人里，因为我怀疑这些模型里的很多价值并非来自机器人数据，我一直认为，要在任何一个具体领域里真正管用，你大概都需要微调。

于是就出现了张力：像 Astra 或 Fable 这样的模型，开箱就很强，但也慢——慢可以克服——可你没法有效地针对特定用例微调。这对其他机器人玩家是一个机会。你看 Pi，或看 General，就能看到他们在利用这个机会，用数据针对特定用例做微调。苦涩的教训非常强，「在测试集上训练」这个想法同样非常强，这两股力量都很厉害，我们得看它们最终如何交汇。

跳出这个框架，智能体式机器人是一种夹在两者之间的有趣做法：你可以把这些模型只当成智能体又多拥有的一种工具。如果像我们这样在封闭世界里做事，你会有很多不同工具。某一件事若需要极高的灵巧，也许你把 Fable 放上去；但你未必想这么做，因为 Fable 会非常慢，你不会对所有事情都这样。对真正在部署的人来说，现在可用的工具多了很多，这是一种非常强的机制。

埃拉德

人们也会谈到你说的公共/开放世界，对更私密、更闭环的系统。在公共开放世界里，比如家里的机器人，或在街上陪人走路，你不能忍受互联网或接口调用的延迟，因为你担心机器人会卡住、摔倒，或发生别的事。所以你希望智能尽可能长在设备上，或至少有某些控制机制，为设备提供相关安全。从安全角度看，这是人们有时会拿最先进大模型，和只在端侧运行的专用微调模型做比较的另一面，挺有意思。

鲍勃

这很重要。一方面是安全，另一方面就是速度：机器人通常需要在非常快的时钟周期上运行，这对这些更大的模型来说很有挑战。历史上这通常靠蒸馏到更小的模型来解决。无论是终端用户自己做，还是 Astra 最终变成一个 Luna 模型：它仍能覆盖一些最常见的用例，但可以非常快、非常高效地运行。真正的端侧、设备上的模型，我认为在这里也可能非常重要。它们通常会依赖开源，再通过这样或那样的方式，用大实验室的数据加以改进。

前线部署工程：超级用户、产品化，而不是顾问

↑ 返回总结
莎拉

你在帕兰蒂尔和 OpenAI 都有过非常出色的历程，习惯把事情做得相对快，包括在困难的生态里。可传统智慧是：和拥有物理世界计划的大型在位者合作、让他们改掉重大流程，是很难的。你怎么看待阿尔达的节奏，以及这里到底有多大可能？

鲍勃

为自己做第一方技术，比如为 ChatGPT 里使用而建模型，和为大型企业做东西，有巨大差别。我们的方法是前线部署工程（FDE）模式。这套东西可以说是我们在帕兰蒂尔、早在二〇〇五年就发展出来的。我喜欢这样回忆：二〇〇五年，我经常在北弗吉尼亚的安全空间里，和那些工作流保密、不能带出大楼的人一起工作，还得想办法为他们做出产品。事实证明，为不能把秘密告诉世界的人做产品，是为任何企业做产品的极好训练——因为凡是真正在运转的企业，都有秘密，都不想把知识产权的一切公之于众。

那套过程的结果，就是前线部署工程模式。我认为最大的功劳应归给帕兰蒂尔现任首席技术官希亚姆·桑卡尔（Shyam Sankar），而我的工作是搞清楚如何为它做产品。做法是把工程师嵌入到客户身边。除非已经有一位准备使用该功能的客户，否则我不会去开发这个功能。所以我想到产品路线图时，起点往往不是「我要去做这个功能」，而是「我怎样找到一个需要这个功能的客户，然后才能去做它」。

因此你必须走进这些企业、理解它们，但你仍然想快。怎样才能快？通常要先找到少数超级用户。很早以前在那家机构，有一位叫莎拉·亚当斯（Sarah Adams）的女士，大约有一年时间几乎是帕兰蒂尔唯一的用户。我会去见她，她会说这东西不好用，我就说那我得去修。后来它好用了，突然就有更多人用了起来。关键是那极少数非常强、愿意和你一起熬过痛苦的用户。

前面讲过阿尔达在安杜里尔的第一位用户，一位想为作动器做虚拟装配的首席制造工程师。我没说的是：作为第一位用户，这对他是极其挫败的过程。他能做出巨大改进、并在那只作动器上行动得非常快，只是因为我们的产品负责人就坐在他旁边。每次他做一件事、结果不像他希望的那样，我们的产品负责人就坐在那儿做记录；两周后，那些问题就都能用了。

莎拉

感谢一号用户。

鲍勃

没错。而且这个过程不会结束。六个月后我们还在安杜里尔，对方说：去看看能不能把导弹造得更快。这只有在你找到导弹团队里的那位超级用户时才成立——他现在感兴趣的产品，零件数大约是我们最初那只作动器的一百倍，也就是多了两个数量级。开箱时产品再次不太能用。你找到那个用户，和他一起把它打磨到能用，然后他再介绍给其他人。

做企业销售时，你很早就想找到那位有愿景的人。这来自经典商业书《跨越鸿沟》（Crossing the Chasm）。传统上，那位有愿景的人是赞助者，你确实需要赞助者；但这本书没写的是，你还需要一位用户：一个真正愿意用你的软件去达成一项结果的人。

莎拉

如果你两件事都做到了，那么即便是非常大的组织，处理问题的速度也会比你预期的更快。

鲍勃

其实并没有所谓「非常大的组织」。有人会问 OpenAI 想要什么，可 OpenAI 什么都不想要。是萨姆想要某件事，格雷格想要某件事，是下面这个团队里的这位研究科学家想要某件事。大组织只是许多非常小的团队的集合，你必须一个问题、一个团队地往前走。

前线部署方法里一个非常有意思的想法是：你不是把软件扔过墙给他们，你是在和他们结成伙伴去达成一项结果。比如搞清楚怎样把导弹造得更快。除非客户成功了，否则你就不算成功。一旦达成那个结果，你就可以环顾其他结果，并赢得去做更大事情的权利。对我们来说，也许是去做飞机，和安德鲁（Andrew）一起做 Fury；也可能是去做对他们而言以美元计更大、更能推动针的完全不同的问题。若你没有先表现出某种卓越，他们也许不会愿意信任你这家创业公司去解决那个问题。所以在企业内部，很多时候就是把已经取得的成功、已经达成的结果像滚雪球一样做大，同时仍把这些烘焙回你的产品里。

我认为现在很多尝试前线部署方法的人，搞错的地方在于：他们把它看成「我只是向现场派一些工程师，让产品在现场能用」。相当有名的是，人们曾经不相信这套方法有效，在二〇一五到二〇二〇年，它被广泛嘲讽。

莎拉

大家觉得它永远不会有杠杆。

鲍勃

对。这些人不过是顾问，帕兰蒂尔只是派一群顾问去做事。直到帕兰蒂尔成为一家市值三千亿美元的公司并开始盈利，人们才开始跟做。差别在于，他们并不只是顾问。前线部署策略是一种教你如何做产品的产品策略。前线工程师是产品与用户之间的空隙，他们在填补这个空隙；如果他们必须一直填下去，你就得不到杠杆。相反，你必须把他们看到的东西产品化，再烘焙回你正在做的事里。这样才能快速前进，发现新事物，并把这些东西做进产品。

超级智能的物理后果：工厂建造工厂，机器走向星辰

↑ 返回总结
埃拉德

如果把这一切推到极致：你逐渐拥有一支部署在多个行业的前线工程师大军，学得非常快，不断迭代，做出大量随后被规模化复用的产品，这一切会走向哪里？你对终点的愿景是什么？

鲍勃

我想回到一开始关于超级智能的讨论。我们先谈了如果只有数字超级智能会是什么样，以及铺开大量算力是超级智能的必要条件。但超级智能也有后果。我很喜欢达里奥（Dario）那句话：数据中心里的天才之国。可如果他们只能坐在数据中心里思考，你给他们发邮件、他们再给你回邮件，他们做不了太多事，他们被困在数据中心里。

智能已经变便宜了，它的互补品是什么？一边是感知，一边是行动。当我们拥有这些通用人工智能时，现在做数据中心里那份智能的眼和手的，是人类。而我认为，未来十年我们会看到各种感知、各种操作的巨大繁荣：会有无人机，会有人行道机器人；我们拥有的每一样物理之物都会带上感知、接到云上，它做的事都会由人工智能来控制。然后我们想做的各种事情，会因为外面有机器人在替你做而真正做成。

有些人以为那只会是一支人形机器人大军。我认为相反，我们会看到形态的巨大繁盛。我们觉得世界是为人类准备的，但若把视野放得更宽，机器人也许会开始长得像各种动物：会飞的，四条腿的，会负重的，会犁地的——其实拖拉机已经是了。所以超级智能的故事，不只是把超级智能造出来、让它住在数据中心里、也许还盘算着如何接管世界；你希望它能走出数据中心，帮助人、为我们做事。我认为，这就是制造的行动号召，也是在超级智能的世界里，整个制造业、包括我们正在做的事，之所以重要的原因。

埃拉德

冯·诺依曼曾提出冯·诺依曼探测器：把能自我复制的探测器送进太空，落到小行星或行星上采矿，造出更多自己，再继续扩散。这是一种用分布式、自我组装的方式大规模探索宇宙的办法，而且是指数式的：你落地，复制十份，那十份再各自复制十份，于是向宇宙铺开。你是否把这看成地球上最终的制造模式？换句话说，最终会不会出现自我复制的工厂？从近乎物理形态的角度看，你如何看待终局？

鲍勃

我们把范围收窄，想得具体一点。假设你的问题是需要更多推土机，于是要建一座推土机工厂。这里就已经有一个递归循环：正确的做法，是把智能部署出去，去制造更多东西。我相信我们很快就会看到工厂去建造其他工厂。但那其实就是机床，我们本来就有。差别在于要以智能的方式来做：建一座工厂要耗费大量人类劳动，为那座工厂设计机床同样如此。我认为这些都会越来越自动化，也必须如此，才能支撑我们所需的、那张巨大的物的网络。

埃拉德

基本上就是数字奇点对物理奇点。

鲍勃

对，甚至不是「对」，而是并肩。数字奇点的一部分，就是把越来越大比例的地壳转化成数据中心，也许这些数据中心也会到太空里。那是一个物理过程，必须由人工智能来指引，就像人类文明在世界各地的扩展，是由人类智能指引的。我认为这是非常近的结果，是人类在未来十年要做的事。

更长远看，一旦机器能够自我复制，它们会是比人类更适合在星辰之间扩散的形态，所以这件事几乎注定会发生。那么你就要确保：它是一件解放人类、让人类从中受益、并尽可能让人类保持控制的事，而不是人类变成一个小小的配角，只留在地球上，看大量大概同样由人工智能生成的视频。

费米悖论：以光速扩散的文明，你只能在到达前看见

↑ 返回总结
莎拉

它们先出去为我们改造星球，好让我们也能探索星辰。

鲍勃

正是如此。我认为，如果我们选择承担，自己也会在抵达星辰这件事上扮演角色。

埃拉德

这在某种程度上又回到费米悖论。人工智能、超级智能、通用人工智能，以及这些自我复制的工厂，都意味着我们本该更早遇到其他智慧生命。也就是说，比起只靠我们的生物形态独自穿越太空，它提高了相遇的可能性。

鲍勃

其实我不同意。我认为这恰恰是费米悖论的一种解法。你想一想，最有效的、在太空中扩散的文明是什么样的？它进入一个恒星系统，很快建起工厂，造出大量自我复制的探测器再送出去，于是你得到的几乎是一道以光速在太空中穿行、铺展的文明波。那我们为什么看不见？因为它正以光速在扩散。我们只会在它到达前几分钟，或者也许几年，才看见它。

埃拉德

我明白了。可论证不就是：它现在本该已经到达了吗？也就是关于太空中潜在文明的密度、它们出现的速率，以及如果你以亚光速发出东西，它最终到达你这里的速率，等等。那会意味着宇宙相当稀疏，对吗？

鲍勃

我觉得这就是一个谜：为什么我们是第一批？如果看德雷克方程里各项因素的不确定性，你会发现，也许这件事其实相当不可能。所以我们是第一个文明，是说得通的。

埃拉德

这取决于你对那个方程做怎样的假设。

鲍勃

对，正是如此。

莎拉

或者它们只是非常遥远。

鲍勃

对，或者非常遥远，在宇宙的某个地方，但和我们光锥相交还需要一些时间。可在某种程度上，证据显示这件事还没有发生。那么我们会不会遇到外星文明？这个论证说：不会。我们只会在它们到达前不久才探测到它们。又或者，我们自己会成为那道波。希望如此：希望我们成为那道以光速在星系中铺展开来的文明波。

埃拉德

太精彩了。感谢你今天来到节目。

鲍勃

谢谢邀请，这很有意思。
