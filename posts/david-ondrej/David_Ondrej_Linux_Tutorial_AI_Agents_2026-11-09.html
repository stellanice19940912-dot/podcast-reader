一句话概述

大卫·翁德雷（David Ondrej）讲解 AI 时代的 Linux：它运行着全球前 500 台超级计算机和最大数据中心的 100%、驱动几乎每一个云端智能体，也正在成为更多人的主力个人系统。他说明如何用一台 Linux VPS，加上前沿模型（现场是 Claude Code 搭配 Opus 5.5）自托管整家公司，省下 Vercel、Netlify、Railway、Datadog 等订阅，并用智能体循环在几分钟内修补高危漏洞。服务器他推 Ubuntu，个人电脑他推 Omarchy；现场用自己做的 Cloudroom 在约 3 分 30 秒内做出按摩预约全栈应用，并演示 15 个子智能体并行。

核心要点

  • Linux 生于 1991 年，却正创纪录地被采用：全球前 500 大数据中心／超算 100% 跑 Linux，每部安卓（Android）手机使用 Linux 内核；网站托管超过 63%；桌面份额约 6%（Windows 77%、macOS 16%）但增长最快
  • 智能体最擅长文本，而 Linux「一切皆文本文件」；只要能控制外壳（shell）、运行 bash，像 Pi 这种只需四个工具的智能体就能做几乎任何事。莱纳斯·托瓦兹（Linus Torvalds）今年 7 月也说 AI 明显有用，并用来查找内核问题
  • 一台 VPS 可替换前端 Vercel／Netlify（轻易每月 20 美元以上）、后端 Railway／Render、自动化 Zapier／Make.com（20–30 美元）、监控 0–30 美元，以及他曾面临的每月 230 美元产品数据分析——他让智能体自托管 ClickHouse 后立刻省下这笔钱。托管商修补 CVSS 9.8–10.0 的高危漏洞常要 1–2 天，自己的智能体循环可在 5 分钟内打补丁
  • 示范用 Claude Code + Opus 5.5（他称强过约 99.99% 的程序员）为 VPS 配置 SSH 密钥并做安全加固：两分半钟后系统更新完毕，防火墙只放行 SSH 和 Web，关闭密码登录并加上暴力破解防护
  • 发行版上，服务器默认 Ubuntu（Canonical 称超 60% 云主机；最新稳定版 26.04，LTS 五年免费安全更新；英伟达 DGX Spark 跑 Ubuntu，他有四台，26.04 内置 CUDA；sudo 等核心工具已用 Rust 重写）。个人电脑首选 Omarchy（DHH 基于 Arch + Hyprland；GitHub 超 4.6 万星；已支持 M1／M2／M3 Max，M4／M5／M6 即将到来；37signals 正把开发者从 MacBook 迁过去）。他预测苹果若 1–3 年不开放 iOS／macOS，重度用户会转向 Linux
  • 现场让已有 VPS 权限的 Opus 5.5 用 Deep API 抓取最新一批 Y Combinator 在投项目，自选「按摩预约」做 MVP（前端／后端／数据库／ClickHouse 分析分离），约 3 分 30 秒构建并部署；随后用 designs 技能出四版设计，两条提示后他说比世上 99% 的按摩店官网更好看。又拉起 15 个 Haiku 5.5 子智能体在云端 Linux 沙箱做营销／SEO 研究，并可用英语切换到 Codex。他做的 Cloudroom 开源免费，独立智能体数即将超过 20 万，宣称是唯一在免费套餐提供云端智能体、且支持任意编排（harness）的应用（并提到 Conductor 被 Meta 收购后关闭云端）

  1. 1开场：Linux 的十年，以及它为何已经无处不在查看原文 →

    大卫·翁德雷（David Ondrej）称这是面向 AI 时代的终极 Linux 教程：我们刚刚进入「Linux 的十年」，它既在成为更多人的主力个人操作系统，也驱动着几乎每一个云端智能体。尽管诞生于 1991 年，人们仍在创纪录地转向 Linux。本期会讲清 Linux 是什么、最适合智能体的发行版，以及如何用一台 Linux VPS（虚拟专用服务器）运行并托管整家公司以节省开支；他强调不必先成为技术专家，能听懂英语就能跟上。Linux 之所以重要，是因为它运行着全球前 500 大数据中心和超级计算机的 100%——也就是全部——而且每部安卓（Android）手机都运行在 Linux 内核上。

  2. 2Linux 的核心：内核、外壳，以及「一切皆文本」查看原文 →

    大多数云服务器同样跑 Linux，因此智能体一旦「分到一台电脑」，几乎总是 Linux；这也是它们最熟悉、最好控制的操作系统。内核是核心，负责运行每个程序并直接与硬件对话；外壳（shell）则是输入 ls、cd、pwd 等命令的界面。另一个关键范式是「一切皆文本文件」，智能体用文本就能操控整台机器。所以像 Pi 这样的智能体只需要四个工具，不必堆到 20、30、40 个：只要能控制 shell、运行 bash，就几乎什么都能做。Linux 的创造者莱纳斯·托瓦兹（Linus Torvalds）今年 7 月对开发者说，AI 显然有用；这位史上最伟大的程序员之一正用 AI 查找内核问题并参与开发。大卫的结论是：连莱纳斯都在用 AI 写代码，你大概也应该。

  3. 3和 Windows、macOS 对比：免费、开源、最好改查看原文 →

    三大系统的出身不同：Windows 由微软（Microsoft）打造、需要许可证；macOS 由苹果（Apple）打造、只随苹果设备提供；Linux 是莱纳斯创立、由所有人共同开发的开源项目，也是史上最成功的开源项目之一，免费且可在任何设备上运行。当前桌面用户份额大约是 Windows 77%、macOS 16%、Linux 6%，但这 6% 正以前所未有的速度增长，也得益于后面会讲的 Omarchy。网站一侧则有超过 63% 运行并托管在 Linux 上。三者里唯一切开源。他的总结是：免费、开源、最好配置也最好改，因此特别适合 AI 智能体。

  4. 4智能体为何偏爱 Linux：用英语部署，模型越强理由越强查看原文 →

    智能体喜欢 Linux，因为设置、配置、日志和工具都是纯文本，而大语言模型（LLM）最擅长的就是文本。所以云端智能体、Codex、Claude、Cursor、Cloudroom 都跑在 Linux 上。过去日常使用 Linux 需要会基本命令、相当懂技术；现在不必了。大卫自称对 Linux 懂得很少，却因为可以用英语对智能体说话、由它决定下一步，而每天都在用、并且用得越来越多。二阶后果是：模型越聪明，Linux 就越强，改用它的理由也越强。有了 Opus 5.5 和 GPT 6.1 Soul，能做的事情一下子被打开——你可以在 Linux 上部署一切，并避开定价过高的平台。

  5. 5安全与省钱：用一台 VPS 替换订阅，五分钟内打补丁查看原文 →

    对智能体说「部署到我的 Linux 服务器」，只要有一台 VPS，它就能代劳，从而替换掉大量订阅。前端的 Vercel、Netlify 轻易每月 20 美元以上；后端则是 Railway、Render——他特别指出 Railway 最近因鲁莽操作出现过很严重的安全问题。从前人们把安全托付给托管公司；今天若处于 AI 前沿、拥有云端智能体和智能体循环，反而能保护得更好：这些公司修补 CVSS 评分为 9.8、9.9、10.0 的高危漏洞通常要一两天，而一个智能体循环能在不到 5 分钟内发现并打上补丁。自动化方面，Zapier、Make.com 轻易每月 20 到 30 美元；分析工具如 Datadog，他最近看到自己和业务的产品数据开支预计每月 230 美元，于是让智能体在 VPS 上自托管 ClickHouse，这笔钱当场省下。可用性监控大约每月 0 到 30 美元，同样能被一台 VPS 取代。自己的 VPS 上你完全做主，安全问题按分钟而不是按周修复；前端、后端、自动化和 cron 定时任务，在活跃用户到好几万之前，一台 Linux VPS 就能轻松扛住。

  6. 6把 VPS 交给智能体：用英语配好 SSH 并连上机器查看原文 →

    买下 VPS 之后，第二步是在面板里做基本设置：操作系统可以随时更改或重置。关键是把 Claude Code 或 Codex 这类强力编程智能体拿到 root 权限，后面的事它们基本都能代劳。大卫切到自己做的 Cloudroom，用 Claude Code 搭配 Opus 5.5，只说「帮我把 VPS 设好」，并附上一张控制面板截图，要求用 SSH 密钥获得 root 权限并列出所有必要步骤。他强调本期最重要的教训：这些智能体的训练语料里几乎有无穷无尽的 Linux 命令和文档，网上例子多到都被收了进去，所以用英语问，它们就能准确告诉你怎么做。它生成了 SSH 密钥（他在画面上打了码）；他把密钥粘到面板的「设置 → SSH 密钥」并保存，再把概览页里的 IP 地址补上——他承认是自己忘了给 IP，而且因为他刚重置过这台机器，智能体一度以为已经连过。随后 Claude Code 便连上了 VPS，可以开始加固和后续配置。

  7. 7两分半钟完成加固：更新、防火墙、关掉密码登录查看原文 →

    Cloudroom 甚至预测到下一条提示就是「开始做安全加固」。大卫并不清楚它会做的每一件事，但认为 Opus 5.5 作为开发者强过大约 99.99% 的程序员，因此选择信任它。若使用 Anthropic 或 OpenAI 的最新模型，就可以把一切委托出去，并因为这些模型在软件开发上已是超人水平而获得安全感。两分半钟后，VPS 已加固完毕：系统全部更新，防火墙只放行 SSH 和 Web 流量，关闭了密码登录并加上暴力破解防护。从前这需要雇一名 DevOps 或真正懂 Linux 的人；现在对 Opus 5.5 说一两句提示即可。他预告后面会用同样的方式部署全栈应用——前端、后端和产品分析都可以放在 VPS 上——然后转入发行版该怎么选。

  8. 8怎么选发行版：服务器默认 Ubuntu，26.04 还内置 CUDA查看原文 →

    发行版是在同一套 Linux 内核上打包工具、应用和桌面后的不同风味，常见的有 Ubuntu、Fedora、Arch、Omarchy、Red Hat 等。Ubuntu 基于 Debian，最适合服务器、云和 AI 智能体；Debian 是「原版」，以扎实的服务器著称；Fedora 基于 Red Hat，走最新稳定技术；Arch 独立演进，适合自己动手、永远跟上最新并高度定制；Omarchy 基于 Arch，桌面好看、友好且为智能体而造，DHH 想让人更容易从 Windows 或 macOS 迁过来；Alpine 适合很小的 Docker 容器；Linux Mint 基于 Ubuntu，面向离开 Windows 的人。服务器上 Ubuntu 是默认选择：由 Canonical 打造，他们称云上份额超过 60%（自家数据，但大卫觉得可信），这指的是所有云托管而不只是云端智能体。最新稳定版是 26.04，LTS（长期支持）提供五年免费安全更新——他猜这个缩写是某种「终身支持」——智能体也非常熟悉它，所以他自己所有 VPS 都用 Ubuntu。英伟达（NVIDIA）的 AI 机器如 DGX Spark 跑的就是 Ubuntu，他为本地 AI 配了四台；26.04 还内置 CUDA，对优化推理很关键。sudo 等核心工具已用 Rust 重写，更快、更省内存和磁盘，也因为内存安全而更少漏洞。Ubuntu 适合 VPS、持续集成（CI）、Docker 和 GPU 机器，从笔记本到云是同一套系统，选它很难走错。

  9. 9Omarchy：为智能体而造的桌面，以及苹果只剩一到三年？查看原文 →

    眼下传播最快的发行版是 Omarchy（有人读成另一种发音，他觉得不好听，还拿 Hermes 智能体的读法打比方）。这是 Ruby on Rails 创造者 DHH 目前的主线：Arch 加上 Hyprland，开箱即美观，观点鲜明并把常用工具预装好，避免过去装完 Linux 还要花 10 小时配置的痛点。它为智能体时代而造：你可以让 AI 改任何东西，这在 Windows 和 macOS 上做不到。大卫预测苹果大概还有 1 到 3 年：若不让 iPhone、MacBook、Mac Studio 更好配置、不给更多 iOS 和 macOS 的权限，人们就会转向 Linux 或 Omarchy——谁也不想再在设置里一项一项手动点。他刚演示过：在 Cloudroom 里只跟 Claude Code 编排中的前沿模型说话，不拨任何开关，就能完成加固、更新、锁定和启用防火墙。能用语音让智能体改电脑上的任何东西，这个价值太大；若苹果和微软在一到三年内不开放，很多重度用户就会离开。Omarchy 在 GitHub 已超过 4.6 万星，每天都有开发，有数百名贡献者和多位科技亿万富翁赞助；以 2026 年的增速（不是历史装机量）看，这是他心目中当下最热的发行版，也是个人电脑的第一选择。它已能装在 M1、M2 和 M3 Max 上，里面是 Linux 与 Hyprland：窗口自行平铺，全键盘驱动，每项设置都是文本文件，因此 Claude Code、Codex、Hermes 都能只靠你开口就改整个操作系统。这最适合开发者笔记本；DHH 的公司 37signals 正把开发者从 MacBook 迁过去。苹果硬件仍是世界顶尖，但若软件不开放，人们会因智能体变强而弃用苹果软件。DHH 已宣布即将支持 M4、M5 和 M6，无论哪一代苹果硬件都会被覆盖。

  10. 10现场做应用：抓 YC 点子、按摩预约 MVP，以及自托管 ClickHouse查看原文 →

怎么选发行版：服务器默认 Ubuntu，26.04 还内置 CUDA

首先，什么是 Linux 发行版？Linux 本身只是核心，也就是 Linux 内核。发行版再在这之上打包工具、应用和桌面，把所有东西捆在一起。所以内核是同一套，风味和适配却各不相同。你有 Ubuntu、Fedora、Arch、Omarchy、Red Hat，还有很多。我们把几个大的过一遍。

Ubuntu 基于 Debian，最适合服务器、云和 AI 智能体。然后是 Debian，也就是「原版」，以非常扎实的服务器著称。

Fedora 基于 Red Hat，走的是最新的稳定技术。Arch 以自己为基础，不依附别的系统，最适合自己动手、永远跟上最新，并且有很高的可定制性。Omarchy 基于 Arch Linux，桌面很好看，也很友好，而且真正为智能体而造——这是重点。DHH 正在用 Omarchy 做的事，后面我还有几页幻灯片：他想让 Linux 更好上手，也尽量可配置，好让人们能轻松从 Windows 或 macOS 迁过来。

然后是 Alpine，同样是独立体系，最适合很小的 Docker 容器。还有基于 Ubuntu 的 Linux Mint，面向正在离开 Windows 的人。

你真正需要搞懂的两个，是 Ubuntu 和 Omarchy。服务器上，Ubuntu 绝对是默认选择。它由 Canonical 打造，是云上号称第一的 Linux，他们说份额超过 60%。当然这是他们自己的数据，但我觉得可信。所以，超过 60% 的云——不只是云端智能体，而是任何云托管——都在运行 Ubuntu。

最新稳定版是 26.04；LTS（长期支持）则提供五年免费安全更新。我猜这个缩写大概是某种「终身支持」。这意味着大多数指南和 AI 的回答都会默认它，Ubuntu 也非常被 AI 智能体所熟悉。所以我自己所有的 VPS 都在用 Ubuntu。

它还能赢在哪里？很妙的一点是：英伟达（NVIDIA）的 AI 机器，比如 DGX Spark，跑的就是 Ubuntu。我个人的本地 AI 配置里就有四台 DGX Spark；26.04 还内置了 CUDA，这对优化推理显然非常关键。

像 sudo 这样的核心工具已经用 Rust 重写，所以更快，也更省内存、更占更少磁盘，安全漏洞也更少——因为 Rust 是一门内存安全的语言。因此 Ubuntu 最适合你的 VPS、持续集成（CI）、Docker 和 GPU 机器。从笔记本到云都是同一套系统，选 Ubuntu 很难走错。

截至今天，它在 GitHub 上已经超过 4.6 万星。我可以把仓库拉出来：就是它。我顺手给它点了星。这是个很好的项目，而且几乎每天都在开发，有数百名贡献者。多位科技亿万富翁也在赞助它，所以它得到了一些科技领域最聪明的人的支持。

以 2026 年的增长速度来看——不是装机量，因为其他发行版已经存在很多年——这大概是当下最热的 Linux 发行版。所以，如果你打算把 Linux 用在自己的个人电脑上，这会是我今天的第一选择。

而且现在它也能安装在 M1、M2 和 M3 Max 上，你完全可以让自己的 MacBook 以 Omarchy 作为操作系统。Omarchy 里是 Linux 和 Hyprland：窗口会自己完成平铺和样式，全部用键盘驱动，每一项设置都是文本文件。

所以 Claude Code、Codex、Hermes 都能只靠你开口，就重新定样式、更新整个操作系统。这最适合开发者笔记本。DHH 的公司 37signals 正在把开发者从 MacBook 迁到它上面。

再说一次，苹果的硬件非常出色，他们在硬件上仍是全世界最好的。但如果他们不让我们改软件，不给我们更多权限，人们就会因为 AI 智能体越来越强而不再用苹果的软件。实际上，DHH 已经宣布即将支持 M4、M5 和 M6，所以无论你手上是哪一代苹果硬件，都会被 Omarchy 支持。

现场做应用：抓 YC 点子、按摩预约 MVP，以及自托管 ClickHouse

现在让我演示怎样真正把应用做出来。我再次切到 Cloudroom，仍然是 Claude Code 搭配 Opus 5.5。这一点我必须强调：请用前沿模型。不管是 OpenAI 还是 Anthropic，最新、最大的那一档，就用那个。后面你可以再优化，简单任务用小模型；但主线工作、把环境搭起来，请用前沿模型，一切会轻松得多。

现在我们可以直接跟它说话。它已经有 VPS 权限了，所以我可以说：我们来为一门新生意做一款全栈 Web 应用，并加上正经的产品追踪——也就是在这台 VPS 上自托管 ClickHouse。

在选定点子之前，我先希望你用 Deep API 去抓取最新一批 Y Combinator项目，给我一份他们正在投的想法清单。就算你自己没有点子，也可以用 Deep API 去抓取和研究任何东西，这也会让你的智能体强很多。

趁它在跑，第一步其实就是用英语告诉 Opus 5.5 你想要什么。如果你只用 Codex，那可以用 GPT 6.1 Soul。

它没那么好，我跟你说实话。眼下 GPT 系列还不如 Claude 系列。也许 OpenAI 很快会发布 6.2 Astra，或者 6.2 Soul，到时再看。但现在最强的是 Opus 5.5。

无论你想做什么应用，一旦有了好几万活跃用户，单台 VPS 大概就不够了。但我要说的是：起步做 MVP，做大多数项目，都可以托管在一台 VPS 上。不仅如此，你还可以在同一台 VPS 上同时放很多不同的东西——多个网站、多套软件。

一台 Linux 机器，配上 KVM2 套餐，比很多人以为的要强得多。所以你不必再向 Vercel、Netlify、Railway、Render 付钱。服务器是你的，你只用智能体控制它，并按自己的需求去配置。

来看看它研究出了什么。这些里面，哪些最适合现在做一版又快又糙的全栈原型？要带数据库，也要带产品追踪和 ClickHouse。先给我这份清单里的前五个选择。另外，这些创业公司你其实一个下午就能重做一遍。护城河就是速度：如果有人还在谈别的，真正的护城河是心态、态度，以及你能多快行动。

五个方向包括：牙科预约应用、保险报价、食品储藏室追踪、员工辅导应用等。我先得说，我不知道 Y Combinator 为什么在投这些，看起来都没有特别革命性。我改一个接近的点子：做按摩预约应用，同时面向顾客和店主。

就把它做成一个简单的 MVP，别想太复杂，越简单越好。并确保一切都部署、托管在这台 VPS 上：前端、后端、数据库，以及基于 ClickHouse 的产品分析，要正确分开。

很疯狂的是，好多产品其实只是套在 ClickHouse 外面的一层皮，除了收集你的数据再每月收你好几百美元，没做什么别的。有了大语言模型和智能体，反而更容易直接去选最好的服务：哪个性价比最高、产品最好，你就能比没有 AI 时做出明智得多的选择。这件事无论你是在买衣服、买新车，还是在决定用哪个平台、哪套软件，都适用。

咨询前沿智能体和前沿模型，能大大降低你做错误决定的概率。一台 VPS 上你可以跑很多不同的东西：自动化、你的 n8n 工作流、Make.com 类自动化；你也可以在 VPS 上重做自己的 Manus 或 Instant，也许我以后会单独做一期。单台 VPS 就能轻松扛下这些。

Cloudroom 与进阶工作流：3 分 30 秒上线，15 个子智能体并行

我认为它是世上最好的 ADE（AI 开发环境）。事实上，Cloudroom 上的独立智能体数量即将超过 20 万；它也是世上唯一支持把任意编排当作云端智能体来跑的应用。在 Conductor 被 Meta 收购、并且对方要关掉云端之后，我非常有信心：Cloudroom 是云端智能体的最佳选择。它内置了云端智能体支持，而且我们是世上唯一在免费套餐里提供云端智能体的。

如果你想继续用自己最新的模型、最喜欢的编排，以及已经付过钱的订阅，可以在 Cloudroom 里统一使用这些推理和 token，一个地方同时支持本地和云端智能体。地址是 cloudroom.dev，我也会把链接放在视频下方。如果喜欢这个项目，请在 GitHub 上给它一颗星，我会非常感谢。

来看看我们的智能体做完没有。做完了。哇，3 分 30 秒，伙计们，3 分 30 秒：它不但部署并配置好了 VPS，连应用也做出来了。那就让它在我的 Brave 浏览器里用新标签页打开。

你真的可以对智能体说这样的话，它就会去打开。看，出来了。非常简单。这次我开的是中等推理力度，所以我可以再给它一张截图，让它把前端重新设计得更定制、更独特，做到最好、更有辨识度。你完全可以这样要求，然后再部署。

我们这个应用实际上拆成了多少个不同的服务？四个独立部分，整套东西部署在我们自己的技术栈上。伙计们，这在软件构建和托管上是彻底革命性的。所有这些部署平台都将不得不去适应。前沿编程智能体，加上 Linux，再加上一台 VPS，能做到的事情非常夸张。

现在我让它重新设计。等一下，我发错了截图，发成了另一块屏幕的画面；但因为它是前沿模型，还是听懂了我的意思。另外，我在 Cloudroom 里做设计时，通常会说：给我看落地页可能的四种设计，调用 designs 这个技能。

你可以给技能打标签。刚才那条是我语音输入的，我删掉重来。你只要写 designs，给任何技能打上标签，智能体就会在聊天里内联展示给你。Codex、Claude Desktop、Cursor 里你已经熟悉的功能，这里都有，包括子智能体。

我新开一个线程，很快示范一下：拉起 15 个不同的子智能体，每个都用 Haiku 5.5，去分析当下正在起作用的不同营销策略，比如 SEO。不必是软件开发，营销、销售、研究都行——你用 AI 智能体在做的任何事，都可以单独拉起子智能体。

每一个都在云端运行。你看左边图标上有「云端智能体」，意思是它跑在自己的 Linux 沙箱里，不在我的电脑上。我让它拉起 15 个子智能体，它会很快在自己下面再拉起一批，而且每一个子智能体也跑在隔离的 Linux 沙箱里。Linux 真的非常强：它在驱动 Cloudroom，也在驱动这台 VPS。看，它们正在被拉起。

正常情况下，我同时跑 15 个 Claude Code 实例，还在用 OBS 录像，电脑就会开始卡。但现在完全不卡，因为这些都跑在云端。就算我断网，就算我合上电脑，它们也会做完。

我刚让它归档，它就把它们全部归档了，接着会用另一种编排重新拉起。所以你可以用一个智能体当经理或编排者，用另一个当工人。现在它正把它们重新拉起——字幕里听成了 Terra，而我刚才吩咐的是改成 Codex——每一个都在自己的隔离沙箱里，并且并行运行。
