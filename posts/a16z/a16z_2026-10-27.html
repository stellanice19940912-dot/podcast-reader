顺着阿里说：我渐渐不再想「这是不是电脑操控任务」。它们常常连在一起。我们把电脑操控看成模型的万能 API——要做成一件事，它就使出该使的手段。任务越野心越大，旅程中某处就越可能碰到电脑操控。我唯一不太伸手的，是简单到我点两下就更快的事；但等它再快一点，也许我连这都不干了——用语音指挥，它跟我一起用电脑。对企业用户，怎样让他们安心？你们已经完全「入脑」了，但企业常有犹豫：人点过去也许更差，可总觉得有问责、那人受过训——经典反驳都在。你们怎么说服？

确实。跟企业聊很多。我们想成两层。第一层是确定性控制——这最给企业安全感：即便我们的模型已经最对齐、抗提示注入也强过多数人，企业管理员仍希望能说：某些任务/数据源太敏感，不许碰。所以我们上了两样：一是给智能体确定性沙箱——能用哪些应用、不能用哪些，能上哪些站、不能上哪些；二是人控回路——哪些动作要人介入，如下载上传要批、进新站要批。这些都是企业可拧的旋钮。第二层是给管理员看我们内部跑过的对齐评测，包括对内与第三方。还有一些「全员基线」帮人建立信任——这太新、太魔幻，有时也陌生。我们在产品设计上下了很多功夫：你想盯着时总能看见光标，动画也有趣，不无聊。企业可定制，普通用户也是：新应用或新站前会问你许可（取决于模式）。这让人不觉得它会在电脑上「跑飞」。你需要一段建立信任的窗口，摸清手感、弄清你要它做什么，然后越来越安心。Codex 的光标好可爱——我喜欢。

细节虽小，但看着它用电脑会给你信心，体验也好。所以用户体验值得投。更宏观一点：现在模型够强、也够便宜能规模化跑了——在你看来，公司该想自动化什么？企业里最有前途的用例在哪？ERP？人机协作完成任务？如果只能挑，你最兴奋看到模型在真实世界的哪里发力？

从我这边看——也想听你们的——大概两大类。第一类是自动化烦人工作流，听起来更无聊；我举点无聊例子——无聊即机会。【笑声】对，正是。ERP 是超大一块；凡你能想到的缩写——ERP、CRM——

詹姆斯

所以两边都会很重要，但会随时间迁移。詹姆斯你怎么看？我同意。这里有很多「工艺」——阿里和他团队做出漂亮产品，你们懂，光标那些都砸进去了。做出能「拿在手里」的好产品，需要大量工艺。若互联网变成一张没有面孔、只剩智能体互相对话、人什么都不用的东西，我会很难过。我不认为会那样——因为工艺、手作软件的感觉：设计者真正懂用户想要的体验。比如我太太最近迷上一款桌游，名字我忘了，大概是连五子赢，好像叫 Omach。她在线跟朋友打老被虐，我说：我给你做一个战术训练器，过各种开局让你变强。我做了第一版——知道她喜欢怎样学、哪种方式更合她——就能把软件打磨成对她手感很好的东西。这类个性化软件，今天也许还像只有技术人会做；但你若——

——往几年后想：任何人都能很快为利基场景做出高度合身的手作软件，那是个很美的世界。训练结束，她的教训与失误可以有智能体总结成文字；但她真正跟 AI 对练、变强，那部分必须人自己做。所以我偏多头：我不认为 UI 会消失。稍微岔开原问题——便宜软件的压力会逼软件必须更好；但我不认为会变成「一切都有 MCP 和 API，电脑操控再也没用」。

太爱这点了。人骨子里就是为直接操控接线的——你想用手去挪、去做。过去软件常常「一套打天下」，为百万、千万、亿级用户设计；我们会进入一个时代：任何软件都可以为一百个人、甚至一个人设计——

——那会个人、独特多少。我的心智模型大概两桶。消费侧：你要么从用中得到快乐、享受，要么从中学习——重点不是效用，是交互或学习的愉悦，你愿意花时间。B2B 侧：你可能要智能体干完一堆烦人活，但也有「审计日志」的概念——交互方式可以个性化，但产品本质是：我这个人类用户设目标，能理解逻辑，却不必跑完整条指挥链。任何 B2B 用户仍要搞清：这笔款为什么付出去，回看摘要，能说「三十天后付给这人、打这个折」。他们要智能体执行，但仍要某种控制——这需要某种 UI。而且若我们越来越相信 AI 会多干这些，那部分 UI 也得用得爽——凭什么要忍受烂软件？

会不会出现新一类软件：有传统界面，底层又用智能体；有时这些智能体再用电脑操控去自动化遗留软件，给你更合身、更专用的体验——我很期待那一类。

有点像我们内部爱说的「共享智能层」：你的智能体在别处用遗留软件、在别处做事；你若在用某个应用，应用也想拿到那层上下文，才能给更好体验。若每个网站各有智能体、互不跟你的智能体说话，世界会很碎片。怎样让智能体插进来、用你的其他软件——接下来几个月会很好玩。

喜欢你们聊这个——人机交互的重要性被低估了，尤其若你想产品成功。人习惯协作，你希望任何智能体能嵌进团队。好奇：若你明天开公司，想用电脑操控解决企业里某条工作流，你会怎么想？失败时要知道、要能跟人沟通，还是做成黑箱？若此刻跟创始人说话，你会给什么建议，让他们用你们的模型与能力去解决企业问题？在我看来，这极大取决于模态——

——你是小团队，想让个人更高效地用团队在用的某软件；还是你在造的东西本身要去交互现有软件，于是云端某处机器在后台做电脑操控？这会大大影响人机协作形态。前一种，我们很多产品就在服务：你坐在 ChatGPT 前，可以有很好的协作。后一种，你也许用 API 自己实现电脑操控，然后就要想：何时人在环？智能体何时报错、报成功？要不要摘要，免得通知轰炸「发生了A、B、C」——那种你最终会忽略。詹姆斯你怎么看？

阿里

我和阿里加入 OpenAI 前都创过业，我对创业仍很看好。问题常落到：还有没有护城河？实验室在做事时，创业公司还能啃什么？大概两件事。一是可做的事太多——我们现在虽大、成千人，内部仍很紧，每个问题的团队都不算大。若你深刻懂某个问题、有行业专长、懂监管、懂获客与服务，田野仍很绿；电脑操控等 API 工具会让你加速。今天护城河某种意义上就是速度与付出。二是很多垂直行业 AI 渗透慢得多。前几天跟一家公司聊：他们用电脑操控帮餐饮集团拍后厨仓储，用视觉根据次日客流预测缺什么，再操控采购软件下次日食材单，并进 ERP 调排班——因为去年同期节假日客流更高。这些餐饮集团不是熟悉全套工具的科技公司。我们在旧金山容易想「实验室什么都能做、人人装 Codex 就行」；但对普通美国人、中小企业主、一般企业：理解工具能力是一，连得有意义是二，部署是三，运维是四。复杂工作流要串很多零散软件时，电脑操控很适合把端到端接上，再做成客户「拿在手里」舒服的 UI——机会仍很大。说说接下来：电脑操控智能体前沿你们兴奋什么、能分享什么？

我已点过：我们很兴奋速度，很兴奋把电脑操控做到超人；也很兴奋把不同界面揉在一起、把多模态输入输出合起来，让跟电脑的体验更流畅。眼下很多电脑操控偏后台——交给智能体一个任务，我去做别的，这其实是巨大优势；但未来也会有更多你与智能体的实时协作。我很期待这块。其余就是更好、更便宜、更易得、更好用——

——对，真正能碰到一切。有了 Dot，我们给人们云端电脑；Tragic work 也有云浏览器。我兴奋的一点是让体验更连贯：今天你可以装 Chrome 扩展，用上密码管理器和 Chrome 里的一切；桌面应用里又有应用内浏览器，cookies/密码另一套；云电脑又是另一套。对普通消费者很懵——为什么四个浏览器互不通？一个开的标签会不会出现在另一个？怎样让电脑操控从企业与硬核尖端用户的产品，变成普通人也能懂的东西——有点像矛盾修辞：电脑操控其实是最好懂的 AI 产品，因为——

——就是 AI 在用你的电脑；但不同状态、不同使用位置的实现细节有时会渗出来，就难 intuitively 抓住。把它做成消费级、更好懂、更连贯——这是我下个季度很兴奋的。

这又回到：仍是人在启动智能体；UI、控件越好用越爽，人拿得就越多——这是原则。另一点想点到：今天产品的另一挑战是——你得想清楚怎么用、记得用、说服自己换掉旧习惯。Dot 那种主动性很强：它能找上门、识别情境、帮你解决问题。我们也会看到更多主动性。我期待智能体适应你，而不是你适应它——那会让人更容易理解、接纳这技术，同时目标仍由人来设定与把握。

詹姆斯

我们还没怎么聊电脑操控的动能、变化有多大——我和 Fitzi 在文章里聊过一点。很想听你们讲轨迹迄今如何、朝哪走。我和詹姆斯在 OpenAI 做电脑操控有一阵子了——

——过去六到九个月极兴奋。开始做这些产品时几乎没人用；今年早些时候因为研究团队的出色工作，模型突然在这类任务上变强；我们又跟内部多团队死磕，做出真正好的产品体验；最近几个月产品突然疯长，人们真的看到价值。但还很早——仍只有一部分用户在用电脑操控，我觉得还会大涨。

对。我一月加入 OpenAI，当时做 Atlas——爱 Atlas，RIP Atlas——我们意识到 Atlas 里智能体体验因种种原因并不是大卖点，用的人不多，很多人当普通浏览器。最近几个月模型能力上来，我们把浏览器与浏览器操控并进已有智能体用量的产品，看到接近 YC 级别的周周增长，总被速度吓一跳。下一个大拐点是云：桌面仍偏生产力用户；多数消费者在手机上。怎样给每个聊天用户、给每天只拿手机过日子的人一台强大电脑——他们甚至不必懂怎么用，它就替他们把事做成。那会把它带到十亿用户。

感觉电脑操控智能体动能已经很大，现在到了：怎样放进更多人手、让他们信任、觉得真能用。你前面说的连贯体验——一旦那块好很多，消费者会更安心，也会更自然。

同意。我们正处在电脑操控的规模化时刻——消费与企业同时。很期待它走向何方、人们用它造什么。
