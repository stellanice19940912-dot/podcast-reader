一句话概述

a16z 普通合伙人马丁·卡萨多（Martin Casado）与阿尼什·阿查里亚（Anish Acharya）对谈大卫·海涅迈尔·汉森（David Heinemeier Hansson，DHH）。谈话从 Ruby on Rails、Basecamp 和电子邮件服务 HEY（hey.com）讲到他正在做的 Linux 发行版 Omarchy——他称之为「智能体时代的第一个原生操作系统」。DHH 认为 macOS 与 Windows 不适合智能体，Linux 过去的短板反而成了智能体的优势；他谈品味会不会被代码生成取代、什么才算超级智能、前沿实验室与开源如何相互制衡，以及他想在三年内让 Omarchy 的用户超过 macOS。后半段转向该追随谁、人工智能文化战、化名黑客回归，以及九十年代 Demo 文化里那些「有性格」的电脑。

核心要点

  • 过去约五到六个月，DHH 没亲手写过一行 Omarchy 代码，却通过智能体写出了数十万行；当前这个开始走红的版本，是他和搭档瑞恩·休斯（Ryan Hughes）用大约两个半月业余时间做出来的。
  • 他认为 macOS 和 Windows 不适合智能体时代：Linux 过去让人头疼的命令行、配置文件和难懂报错，正是智能体最喜欢的三件事。苹果还在弹出更吓人的提示，劝你不要让 Claude 访问文件；他说苹果有变成「智能体时代的 AOL」的风险。
  • 他明确说自己现在每天工作 16 小时。因为几个像素不对就可以立刻改，品味和完美主义的门槛塌了。37signals 大约 60 人，他从没想过换成 6000 或 6 万人的公司，但愿意指挥一支相当于 6 万人生产力、却没有人事和委员会成本的智能体舰队。大部分时候他只用一份 200 美元的 20 倍订阅；三个 Claude 订阅里，过去三个月只有两周接近用满。
  • Omarchy 背后的非营利组织 Omacom Foundation 已筹集约 2300 万美元的 token 与捐款。社区里有人用大约两周重写了 Adobe Lightroom，他还觉得比 Adobe 花十五年、数千万美元做出来的更好。他的口号是：先拿下曼哈顿（桌面），再拿下柏林（移动）。
  • 他的「狂妄幻想」是三年内用户数超过 macOS——他给出的全球 Mac 用户大约是 1.8 亿，连 C 级互联网服务都算不上。Quattro 版本全面拥抱智能体后已有数十万人使用；他甚至说可以 12 个月后再看能不能撼动 Mac，但不会把多数概率押在这 12 个月上。
  • 他认为必须有开源和开放权重，才能让前沿实验室保持诚实。他为美国两大实验室领先而高兴，但不希望出现政府用枪杆子维持的双头垄断，或重演谷歌与 Meta 吸走在线广告价值链约 99% 的故事。本地模型上，他大约六个月前还写过「买高性能个人电脑很傻」，现在英伟达 DGX Spark 已能在桌上跑可用的 Qwen 3.8 Flash Next，售价只需数千美元。

  1. 1从 Rails、Basecamp 到 Linux查看原文 →

    开场先抛出整场访谈的钩子：DHH 认为 macOS 和 Windows 不适合智能体时代；Linux 过去难用的三件事——偏命令行、一堆不好懂的配置文件、难解的报错——正是智能体喜欢的东西；源代码里没有护城河；明年出现真正的超级智能也不是不可能。正式开场后，主持人请他快速介绍自己。DHH 说自己做互联网软件大约 30 年，其中约 23 年在做 Basecamp——那个在「软件即服务」这个词出现之前就存在的项目管理工具，发布时间就在 Facebook 上线的前一天或后一天。Ruby on Rails 就是从 Basecamp 里抽出来的，后来被用来做 Twitter、GitHub、Shopify、Airbnb、Coinbase 以及无数其他应用。Basecamp 现在卖到第五版，Rails 到了第八版；五年前他们发布了电子邮件服务 HEY（hey.com）。这大约 25 年里他还写了四本书，包括《重来》（Rework）、《远程》（Remote）和《工作不必那么疯》（It Doesn't Have to Be Crazy at Work），并每天在 X 上写下对公司经营和技术的看法。眼下他在做 Linux 发行版 Omarchy，自称「智能体时代的第一个原生操作系统」，已经让几十万人从 Windows 和 Mac 迁过来，想把喊了 25 年的「今年是 Linux 桌面之年」变成真的。他桌面上的第一套发行版是 Ubuntu，也就两年半前的事；服务器上的 Linux 他从上世纪九十年代就在用。从 2001 年换到 Mac OS X 的 Beta 4 起，他一直是苹果生态的人，直到他认为苹果走偏了：迷上了轻松的服务收入，从别人的生意里抽走 30%，可以花十年开发一辆永不出售的汽车，也可以推出一款像滑雪面罩一样彻底失败的产品，都无所谓。他为苹果鼓吹了几十年，终于受够了，转到了 Linux。

  2. 2为什么智能体会让 Linux 成为更好的操作系统查看原文 →

    主持人问：Linux 桌面这一次的「为什么是现在」，有多少是因为苹果和 Windows 把自己的生态搞浑，又有多少是因为人工智能让人真的改得了操作系统？主持人自己前一晚还试过，只要对智能体说「改我正在用的操作系统」，它就能改，而且能用。DHH 认为，苹果对开发者不友善只会影响少数人，做商业软件的人还是得上应用商店，这件事本身不会让大批用户改用 Linux；真正会让人成群换系统的，是智能体时代。他提到当天又有新消息：苹果把在 macOS 上用智能体变得更难，弹出更吓人的提示，劝你不要让 Claude 访问文件——可智能体不碰文件又能做什么？Omarchy 这边则完全站在相反方向：过去五六个月，整个操作系统都由智能体开发，他没亲手写过一行代码，却通过智能体写出了数十万行，并用同样的能力加速发行版本身。用户想换开始菜单、挪时钟、换日历，或给系统已有部分加功能，用提示词就能做，快则几秒，慢也只要几分钟。他认为，只要真正泡进去五分钟，就不会再回去；macOS 和 Windows 都不适合智能体时代，而智能体很快会成为这些电脑上唯一要紧的事。他举了个具体例子：在 macOS 上给不同工作区重映射快捷键，只能手动进设置、一格一格点、一格一格填，无法以智能体的方式完成——就算用「计算机使用」去点，也显得笨。Linux 过去的三大短板，恰好变成今年你该用 Linux 的理由。他说苹果正冒着成为「智能体时代的 AOL」的风险：筑起围墙花园，旁边放着 Genmoji，不必用前沿实验室的真正智能体，只要接受一套被稀释、被保护的替代品。多数人不要 AOL，而要开放的互联网，这正是 Omarchy 想给的。

  3. 3第三移动平台还有没有机会查看原文 →

    主持人问移动端会怎样。DHH 说移动端也必须同样改变，而他也因此更兴奋先从桌面入手：25 年来第一次，第三套操作系统的窗口打开了。上一次能在全球市场份额上留下痕迹的新系统，还是 2001 年的 Mac OS X；此后窗口关闭，谷歌和苹果把那块从别人生意里抽 30% 的市场一分为二。微软曾砸下数十亿美元做 Windows 手机，却因为没有应用——换过去连 Instagram 都没有——而夭折。现在变了：Omarchy 社区里有人用大约两周时间重写了 Adobe Lightroom，而这是 DHH 唯一还留着一台 Mac 来跑的软件，因为他的插件和相机预设都在上面。他觉得那不只是复制，而是比 Adobe 花大约十五年、数千万美元甚至更多做出来的更好。把这件事搬到手机上：如果某个应用不存在，就会有人用五分钟「氛围编程」做出来。生态锁定期望的是应用是否齐全，而智能体时代里，软件开发的价格和难度已经降到接近零。他的口号是：先拿下曼哈顿（桌面），再拿下柏林（移动）。主持人补充：五年前做第三套移动生态几乎注定失败；现在用一点 token 预算，就有可能复制前一万甚至十万个应用，而且许多应用也许根本不必复制，因为智能体可以直接完成本来要打开应用去做的事。DHH 同意，并说自己已经不再用文字处理器：合同交给智能体起草，他用 Markdown 审，满意后再生成看起来很漂亮的 PDF。他正在筹建 Omarchy 背后的非营利组织 Omacom Foundation，已经筹集了大约 2300 万美元的 token 和捐款，因此签过很多合同，每一份都由智能体完成，没有用过文字处理软件，连签名和寄出都交给智能体。照片也一样：没人会再花几十上百小时去学 Photoshop 的细枝末节，想改照片或去掉画面里某个人，直接让智能体做就行。这些应用过去不只是软件，还是一门要学上数年的职业，智能体正在整类消灭它们；即便你仍想要应用，社区里已经可以现做。他形容现在还是一种奇怪的早期形态，速度大约每秒 50 个 token，打开超快模式则是 12，还不足以让东西「活起来」。而 Fireworks 两周前在大会上演示了每秒 1500 个 token：从「给我做一个俄罗斯方块」到游戏跑起来只用四秒，接着改成横版射击、加激光、加炸弹、把怪物变大，一切都在现场实时变形。这还只是今天能做到的 1500；一两年后模型跑到每秒 10 万甚至 100 万个 token 时，历史性的生态壁垒会消失。当前这个开始爆发的版本，是他和主要搭档瑞恩·休斯用大约两个半月业余时间做出来的，却要去跟微软的数千名程序员、以及大公司里全球数万名程序员竞争。风险投资过去二十多年把钱砸进开发者和长达数年的跑道，现在被压缩到几天、几周，最坏也只是几个月。就在他做 Omarchy 期间，模型从 Opus 4.8 跳到 Soul，再到 Opus 5.5，跨度巨大，而且很可能圣诞节前还有一回更新，这些跳跃还在加速。因此，任何还认为即便有数百万行源代码也能构成护城河、能保住生态的人，都是在自欺。

  4. 4人工智能写代码之后，品味还重不重要查看原文 →

    马丁说自己一直把 DHH 看成手艺人，设计和人机工效都极好。他自己 50 岁了还在玩《星际争霸》（StarCraft），最近一次补丁改的是已经存在约 20 年的幽灵单位数值——都是和代码行数无关的细微调整。他的问题是：软件的护城河会不会其实就在这些长尾的设计选择里，变化并没有那么大，仍然需要热爱软件的人把品味灌注进去，只是不再手写一行行代码？DHH 说正是如此。他觉得自己能把更多品味、愿景和完美主义放进软件里，因为从发现几个像素不对到动手改掉，中间的屏障已经塌了。任何不完美的软件，现在都是一个可以打磨到完美的机会——这就是他现在每天工作 16 小时的原因。他曾写过整整一本《工作不必那么疯》，而此刻工作是彻底疯了：对完美主义和手艺人来说，突然被赋予了超能力，这令人上瘾，也危险，至少会伤到健康和睡眠。氛围编程项目往往在最爽的前 80% 就停住，后 20% 还摇摇晃晃、有漏洞，人就失去兴趣；而他自称有福，多巴胺全在最后 2%，前 98% 他其实不太在乎。目前他还没找到能「一枪打准」、设计和实现都一次完美的闭环，暂时仍需要人的眼睛，但一旦补上这只眼睛，下面就像一支没有协调成本的大军。他从来不想把大约 60 人的 37signals，换成 6000 人或 6 万人的公司——那听着就是折磨：争吵、人事、委员会。但通过智能体去调动相当于 6 万人的生产能力，他感兴趣了：没有那些成本，只有他和一支高带宽的智能体舰队，去执行对「完美电脑」的凝练设想。他引用 Shopify 首席执行官托比·吕特克（Tobi Lütke）的说法：周末只和智能体在一起像进入超空间，再回到一家 7000 人公司的办公室，就要面对人事、团队、汇报和各种杂事；用现在这种方式，不必受那些罪，结果却相似甚至更好。更惊人的是便宜。他大约一个月前在 X 上调侃自己「有无限 token」，毕竟做了 20 年、已经有钱。可他实际买的只是三个 Claude 订阅；过去三个月里只有两周接近用满，大多数星期只用一份 200 美元的 20 倍订阅就够做完所有事。这还是前沿模型，还没算开放权重、更便宜的模型，或用 Luna 去跑、再做优化。所以这一刻并不只属于钱多到没上限的人。他承认仍需要人，但也不自以为这会永远如此：完全有可能到明年就出现真正的超级智能，在所有事上都强过人类，连打磨完美电脑也强过他。你只需说「给我做一台很棒的电脑」，它就能为你定制 Linux 内核。他正在品尝这个人类也许只是眨眼之间仍能提供增量、同时又拥有巨大能力的时刻；然后他说，也许明年年底我们就都死了，所以先好好享受。

  5. 5什么才算超级智能查看原文 →

    主持人问 DHH 心里有没有一套「超级智能测试」。他自己的测试是：每次新模型出来，就让它去买让自己「具身」所需的一切，预算 2 万美元，房子里不断出现机器人零件和 OLED 显示屏，目标是它自己下单、自己组装出一台能走路的自主机器人——现在还远没到。DHH 说自己没有这样的测试，也许该有，但他的感觉是：在软件开发这件事上，超级智能已经到了。论广度，这些人工智能已经强过他认识的任何程序员；在某些极窄的领域，个别超级程序员还能压过智能体，但把整体能力和速度放在一起看，已经是超级智能。他想做的任何软件，靠提示词再稍加引导就能做出来。不过主持人举的机器人例子让他想到：大约两周前他在中国看了宇树（Unitree）和另一家公司。他刚看过一期德瓦克什（Dwarkesh）的访谈，里面有人说也许明年就有超级智能和快速起飞；宇树的人却说四年、五年，也许要十年。软件这边觉得马上就要发生，做执行器和机械的人却觉得，剥个洋葱也许都很难。主持人说，他用的 GrokBot 认为家里放人工智能的正确方式其实是家庭自动化，于是不断帮他下单相关设备；他觉得自己会先得到《星际迷航》式的墙上会说话、能控制房子的面板，而不是能走路的机器人。他还补了一句：这是模型自己的决定，不是他的——目标给得太含糊，比如「优化人类幸福」，一不小心就会走到回形针最大化。

    主持人问他如何看待前沿实验室与开源，并说一直觉得他很反潮流，对权力集中有很强的立场。DHH 认为开源和开放权重绝对必要，为的是让整场比赛保持诚实，必须有竞争。他职业生涯里有两段时间都对双头垄断把一切瓜分掉感到沮丧。大约 2000 年到 2009 年，互联网曾是一段短暂的避难所：最重要的平台完全开放、完全免费，谁都可以做，不必先请假；移动平台出现后，好日子结束，你又得为应用上架、也就为生意能否存在去求许可，他认为这令人无法忍受。他欣赏 Opus 5.5，也欣赏 OpenAI 在做的事，但如果最后变成双头垄断，尤其是由政府用枪杆子强制维持，会是噩梦。他拿上世纪九十年代的加密战争作比：当时差点禁掉公钥加密，因为国家安全局等机构想继续窃听；如果互联网没有加密，商务和通信都无法想象，对世界经济、发展和网络本身都会是巨大伤害。他认为人工智能正站在类似的悬崖边，不断听到聪明人说「也许该由政府接管」——这让他直呼受不了。即便没有政府接管，两家实验室在商业上把市场一分为二，也会是灾难。好消息是，封闭模型内部的竞争，比他见过的计算机产业任何阶段都更激烈：不只两家领先，SpaceXAI 已经相当接近，谷歌则一会儿在局内、一会儿又像跑到岛上「抽了什么奇怪的东西」，另外还有一批实验室在啃边。更重要的是开放权重模型也已经很好用。他无法精确量化落后多少，但 GLM-5.3 或 DeepSeek Flash 大概落后六七个月，有些任务上甚至不到；他也看不太起刷榜，实验室拿出一份基准说已经追平 Opus 4.8，他一试，真实世界里并不是那么回事。但这些模型已经在场上，能跑在本地硬件上，而且有用。大约六个月前他还写过文章，觉得大家买高性能个人电脑很傻，因为当时能本地跑的模型弱到做不成一件要紧的事；幸好他完全错了。还没到同年年底，一台 DGX Spark 已经能跑真正能用的模型，Qwen 3.8 Flash Next 就完全可用——桌上一个盒子里的智能，售价只需数千美元，这正是他们迫切需要的。但他要的是全部，而不是「非开源不可」的原教旨立场。他为美国拥有两家领先的前沿实验室而欢呼，因为大家能用这些东西来做产品；只要它们被竞争约束住就好，不能出现没有对手、把 token 价格提到每百万 500 美元还照样有人付的「无限印钞漏洞」。社交媒体和网络起飞后，价值被谷歌和 Meta 两家分掉，它们吸走了在线广告价值链大约 99%，只因为广告主愿意为每花出的一美元再多拿回一美分。他认为这是反常而反乌托邦的。两家实验室如果放任不管也完全会这么做，因为资本主义通常就是这样运转，多数时候这甚至算一种特性：它激励投资，人人都想持有下一家谷歌、Meta，或现在的 Anthropic 和 OpenAI 的股份。这些想法要同时放在脑子里：既要开放权重，也可以为前沿进展加油；全部都有，所有人都会更好，才能活在那种无限过剩、人人繁荣的盛景里。

  7. 7比 macOS 更大的计划，以及不要陷入人工智能精神病查看原文 →

    主持人观察到，模型越强，所有人都在爬「野心梯子」：五年前还像魔法的东西，现在会觉得很一般；在 X 上想要一个赞，做个三维东西或会自我改写的游戏，可能只有 40 个赞。他问 DHH，未来 12 到 24 个月里，有没有以前根本不敢想自己能做的东西。DHH 承认这个项目上已经出现「野心膨胀」。项目去年才动手，一开始还是他自己用十根「胖手指」写小段 Bash 脚本，对着 Bash 骂街，能做的事非常有限。他当时只想给自己做一台更舒服的电脑，一个苹果不能主宰命运的地方，为自己、五个朋友和网上少数人来做。后来有了几万用户，一个不错的开源项目，电脑也更好了。智能体到来后，目标从「稍好一点的电脑」变成「我们可以做出完美的电脑」：他用机器 40 年来想要的一切，差不多可以一个人做成。和朋友一起做更有意思，所以他邀请了几十万人同行。看着人们把 Linux 体验成不仅是 macOS 或 Windows 的替代品，而是远更优越的东西，当然会生出狂妄的幻想。他现在的幻想是：大约三年内，规模超过 macOS。他说全世界只有大约 1.8 亿 macOS 用户，在美国、尤其在硅谷看来很大，出了这个圈子其实很小，连 C 级互联网服务都算不上，最大的那些服务有数十亿用户，Linux 当然可以超过这个数。这听着像妄言，因为 Linux 社区把「桌面上的 Linux 之年」这句预言喊了 25 年；但现在加速度已经出现。就在最近四五个月，他们推出全面拥抱智能体的 Quattro 版本，用智能体来构建，并把智能体交到每个用户手里，已有几十万人用起来。于是他想，也许不必等三年，12 个月后再盘点：能不能在一年里撼动 Mac 花二十年、再加上这家七十年代就存在的公司所积累的位置？他不会把多数概率押在未来 12 个月，但也不会排除。如果实验室里的聪明人认为大约还剩 12 个月就会出现递归自我改进、进而出现「人工智能超级神」，那总该有机会推上一套世界排名第二的操作系统。这只是他在自己那块窄战场上的野心；像埃隆那样去殖民所有行星的宏大野心不是他的路，他只想要一席去火星的星际飞船座位，把全部能量押在这个窄范围里。他也不去想 12 个月后的世界会怎样，因为那是患上严重「人工智能精神病」的最快途径。他更喜欢「人工智能欢愉」：对眼下工具所能做的事感到兴奋和乐观。如果去想象再跳两三次、四次模型之后的世界，人会疯掉——人还有什么角色，人类是否还需要存在，会不会都变成回形针。他认为许多人工智能安全研究者就是整天坐着想未来 12 个月最坏的事，最后把自己逼疯。若在 1944 年坐在奥本海默（Oppenheimer）旁边，想象五年后地球一片荒芜、处处核废料，而后来发生的是：原子弹成了世界和平所遇到过的最好的事，他们得到了 50 年没有全面核毁灭的「美丽冷战」。未来极难预测。他唯一喜欢的未来预言是威廉·吉布森（William Gibson）那句：未来已经到来，只是尚未均匀分布。若人人都能做到他现在正在做的、看到现在已经可能的事，国内生产总值每年加快 3%、4%、5% 乃至 10% 的增长，在他看来属于可能的范围；至于一年后模型会在哪里，那就摇摇八号球，再问一次吧。

  8. 8该追随谁，以及人工智能文化战查看原文 →

    马丁说，录制前他和阿尼什刚聊过一个意外而美好的现象：他们成长过程中那些了不起的人，在这波人工智能里重新站出来带路——有 DHH，埃里克·雷蒙德（Eric Raymond）也回来了，还有约翰·卡马克（John Carmack），都是过去 30 年里的中坚。他感谢 DHH 那次「软件已经结束，我们现在是建造者」的演讲，认为他在带一代人走过这段混乱；也问他现在会把谁当作指路的光，该更多地追随谁，因为并非所有人都一起经历过互联网、大衰退、移动互联网的困惑和共享经济。DHH 说，所有他因编程功力而深深尊敬的人，百分之百都已经完全「入坑」，这理所当然：凡是曾用最难的方式做成过事的人，都无法否认这些工具能加速那份工作。也许因为已经成功，他们并不感到威胁。真正别扭的是中间那一大层：多数地方的多数程序员并不是可以安稳财务独立的有钱人，他们觉得自己靠大量苦工和技能挣到了位置，于是焦虑——若明天程序员这种身份消失，大家都只是「做东西的人」，我还是个好的做东西的人吗？他认为对此该有同情，就像该同情七十年代底特律的汽车工人，该同情英国那些最初的卢德派织工，以及所有在自己职业里亲身感到冲击的人。但同情归同情，他不会回到前工业时代，不会拿着锄头和一头牛去过糊口的农耕生活，也不想回到流水线上，靠用手单调地拼装来过一份体面日子。必须向前倾，想办法把大家都带上；而这在一定程度上就是氛围之战。有人也许出于真实的个人焦虑，把自己定位成「反人工智能的那个人」，整个社区甚至会上瘾。若把最让人受不了的、顶着蓝头发的「觉醒」人群，和反人工智能人群画成维恩图，结果几乎是一个圆。某种意义上他们在重演上一轮、也在重演每一场战斗，因为阵线已经这样划好了。讽刺的是：他们不喜欢的那些人先拥抱了这项技术，于是只剩下相反的位置可站，也就只好变成反人工智能的人。大约五年前，当这些人仿佛拥有全部文化权力、可以随时随地取消任何人的时候，他们对未来同样焦虑；现在鞋子换了脚。但也不该掉进陷阱，把一切都看成阵营对决，或把所有对人工智能感到不适的人都说成「蓝头发白痴」——只是每个蓝头发白痴恰好也都反人工智能。可以带他们一起走，让他们明白：你可以有任何感受，但唯一的向前之路就是穿过去。没有人会自愿放弃这项技术，除非最后变成人工智能仓库里的一堆回形针。世界已经不同了，就像莱特兄弟飞起来之后，不会再靠船运送一切。我们有义务往里推。

  10. 10九十年代 Demo 文化，以及有性格的电脑查看原文 →

    主持人提起九十年代的 Demo 文化。DHH 立刻说它在创意上已经回来了：一些最精致的演示出自对做生意毫无兴趣、纯粹因为爱艺术的创作者，他不记得最近一次还有这样的运动。他正把这一切拉进 Omarchy。标志性的视觉效果是屏保：用 ASCII 艺术跑过 40 种 Demo 效果，看起来完全像 1995 年 Demo 派对的开场。他们也保留终端美学，这和 macOS、Windows 完全不同。Linux 发行版历史上常常以为，只要做出 Windows 的「我也能」仿品，大家就会喜欢；可没人想要一份对原本就没那么出色的东西的廉价拷贝，人们要的是专门、独特的东西，而 Omarchy 的美学就是九十年代 Demo 文化。录制前他正在做本机部署本地人工智能的说明：启动一个本地模型可能要几秒，有时甚至几分钟，于是他在加载过程中又塞进一套 ASCII 效果，让很酷的字符在屏幕上飘。有没有功能？完全没有，只是为了让你觉得自己在用一台很酷的电脑——这正是九十年代和 Demo 文化给他的感觉。他当时也玩盗版游戏，那些游戏会有「由 Razor 1911 破解」的开场，文字旋转着出来，那一天就会觉得自己酷了一点。BBS 也是这样：哪怕你的工作只是在推 Excel 表格，至少在那一瞬间会觉得自己活着。他记得那些协议：Xmodem、Ymodem、Zmodem，还有 Kermit——为什么叫 Kermit，没人知道，但听着就很猛。他 14 岁那年在卧室里办过一个精英电子公告板，接了三条电话线；丹麦电信垄断公司的人来装第三条线，看见这个 14 岁的孩子，觉得这怎么可能合法。那人完全正确：这件事完全非法，也完全精彩。他至今还能听见 US Robotics 调制解调器、33.6K 接通时的声音，那是必须被留住的标志性声音。电脑就该有一点神秘，该有很多酷，不该被打磨得那么光。再喜欢苹果，他也觉得乔纳森·艾维（Jony Ive）基本上用铝把电脑的性格抛光掉了；那在一个时期也许是对的，但那个时期结束了，「我们要把黑客请回来」。收尾时主持人问他网上那张漂亮办公室的照片是不是真的。DHH 说非常真，办公室在马里布（Malibu），只是他此刻不在那间办公室，否则会把镜头转过去。那景色他怎么看都看不厌，所以才不断把照片发出来，纯粹为了自己爽：不敢相信自己在这儿工作——这也是资本主义的战利品之一。主持人也打趣说，这间办公室是由商业软件带来的。

所以我极度看好一个判断：macOS 和 Windows 都已经不适合智能体时代。而再过不久，智能体时代会成为这些电脑上唯一要紧的事。我们正全力投入这个想法：过去 40 年围绕鼠标点击建立起来的操作系统，对智能体时代根本不够用。就举一个最基本的例子：如果你想在 macOS 上重映射快捷键，让它跳到不同的工作区，只有一种办法——手动走进设置应用，一格一格地点，填进新的快捷键，再点下一格，再填。你没法用智能体的方式去做。当然，也可以让「计算机使用」去点，但那相当蠢。而在 Linux 这边，过去让 Linux 难用的每一件事——非常依赖终端、有一堆不好弄明白的配置文件、还有难解的报错——这三样正是智能体喜欢的。它们希望每件事都有命令行界面，希望有可预期、可以直接编辑和更新的配置文件，也希望报错里有全部细节。所以 Linux 这些历史上的缺陷，就在今年变成了你为什么该在电脑上用 Linux 的理由。只要你对智能体、对人工智能感兴趣——而到了这一步，任何还在做东西的人，有谁不感兴趣呢？

所以我觉得，苹果现在正冒着成为智能体时代的 AOL 的风险。他们会提供一座围墙花园，这边放着 Genmoji，你不必使用来自真正前沿实验室的真正智能体，只要给我们一个机会，送你一套被稀释、被保护起来的东西。可大多数人不要 AOL，他们要的是开放的互联网。而这正是我们想用 Omarchy 给他们的。

主持

这确实很迷人。因为我觉得，五年前要做第三套移动生态，这个想法几乎注定失败，完全让人望而却步。而现在，用一点 token 预算，我们就能复刻前十、前十万、前一万个应用。对许多应用来说，它们甚至不必被复刻，因为智能体可以直接完成本来要打开那个应用去做的工作。

照片也是一样。你想改一张照片，就说：把这张弄好看。难道你还要花几十个小时、上百个小时去学 Photoshop 的细枝末节？没人会再这么做。他们会让智能体去做，而智能体会做得非常出色，照片回来时已经很好看。或者你想去掉照片里的某个人，你就说：把左边那个蠢货去掉，我只想看这两个人。一下子就好了。所以我认为，智能体会消灭整类应用。这些应用在过去，尤其是 Photoshop 这类，不只是一个应用，它还是一门职业，是你必须学习、有时要花上数年才能做好的事。那当然都很好，但智能体已经把这些接过来了，现在可以不再通过那个应用来做。即便你确实还想要那个应用，我已经注意到、也在社区里看到很多这样的情况：每当你需要某种 Word，或需要某种 Photoshop，基本上都可以现场做出来。

我们现在看到的，还是人工智能一种有点奇怪的早期模样，速度大约是每秒 50 个 token；打开超快模式，则是 12。这还不足以让事物感觉「活着」。就在两周前，Fireworks 在他们的大会上演示了每秒 1500 个 token。他们用一个游戏做例子：从提示词「你能给我做一个俄罗斯方块吗」到游戏跑起来，只用了四秒。然后他们又做了另一个，说做个横版、做个射击游戏，游戏已经在屏幕上跑起来了。他接着对它提示：加上激光，很好；再给它加炸弹；把怪物变大。一切都在现场实时变形。那就是软件未来的预告片。一切都会在现场实时变形。而这是每秒 1500 个 token，今天就做得到。明年会怎样？再过两年，这些模型跑到每秒 10 万、100 万个 token 时，又会怎样？所以方向是清楚的：过去任何人想推出并做成一套新生态时面对的那些历史壁垒，都会消失。不仅生态本身可以容易得多地被创造出来——我们现在这个开始疯狂走红的版本，大约是用两个半月的业余时间做出来的，就是我和这个项目的主要搭档瑞恩·休斯（Ryan Hughes）。

我们要竞争的，是微软那边数千名程序员，是这些大公司里全球数万名程序员。现在突然，这边一小撮人随手做出的东西，不仅有竞争力，而且更优越。这在以前完全没听说过，以前绝不可能发生。再看风险投资：差不多有二十年的历史，所有的钱都砸向开发者，因为你需要开发者来把东西做出来，也需要好几年的跑道让这些开发者去建造。现在突然，这一切被压缩到几天、几周，最坏也只是几个月。而这还只是我们现在手上的模型。就在我做 Omarchy 的这段时间里，我开始这一新阶段时用的是 Opus 4.8，当时已经很好；然后我们有了 Soul，现在又有了 Opus 5.5。从 Opus 4.8 到 5.5 的距离是巨大的。圣诞节前还会再来一次更新吗？很可能。如果没有，那也会在明年初到来。而且这些跳跃还在加速。所以，任何还以为源代码里——哪怕有数百万行——存在着护城河，或以为那能保住他们生态的人，都是在自欺。

所以是的，我仍认为人还有位置，但我也不会自负到相信这一定会永远持续。我觉得完全有可能，到明年我们就拥有真正的超级智能，在所有事情上都比人类更强，甚至在打磨完美电脑这件事上也会强过我。你只需说：给我做一台很棒的电脑。它便会为你定制 Linux 内核，把其余一切也做好，然后就完成了。所以我正在品尝这个时刻：人类也许只在眨眼之间，仍然是多余的那一点、仍然能给过程带来增量，同时又拥有这种惊人的能力。然后呢，我不知道，也许明年年底我们就都死了。所以先好好享受。

本地人工智能里也有大量这样的东西。0x0 就是我们通过 Omacom Foundation 赞助的人；还有 Mia's Lab。两家都是化名的。0x0 的身份我猜其实是已知的，但他用句柄活动。我喜欢这种能量：现在，个人可以凭借人工智能的力量，真正在行业的向前推进中扮演关键角色。因为正如我说的，一旦互联网被装进瓶子、被商业化，大量把事情向前推的前沿工作就被大公司吞掉了。哦，谷歌做了 Chrome，然后它几乎成了唯一的浏览器，再去创造另一个浏览器基本上就不可能了——在 Linux 内核之后，浏览器引擎是人类生产过的最复杂的软件。于是我们把计算机里所有这些要紧的领域都关上了，只有世界上最大的那些公司能做。

而现在我们正在重新把它民主化，交还给黑客文化，交还给那个真正能把其中一些事情向前推动的个人。所以我看向那些人，基本上就是任何在网上用化名做很酷之事的人。我会想：嘿，我得关注这个人，这边正在发生什么。我喜欢这个。这就是反 LinkedIn 文化。它就是这个，完全相反的东西。而其中很大一部分是由 X 灌注进去的。X 为这场整个革命扮演了如此巨大的连接组织角色：对艺术家，对化名黑客，对本地人工智能运动，全都通过 X 连在一起。如果那些蓝头发强盗在埃隆把它带回来之前，不知怎么把那块阵地守住了，我们可能根本不会拥有这一切。它可能全部都会变成 LinkedIn 上的人类渣滓。

我的天，记得。兄弟，它在创意这一面是彻底回来了，太惊人了。一些最精致的演示，出自这些随机的艺术家，他们对做生意其实毫无兴趣，纯粹是因为爱艺术。我不记得最近一次我们还有过这样的运动，这太棒了。我正试着把这一切都拉进 Omarchy。我不知道你有没有试过 Omarchy，但它标志性的视觉效果之一就是屏保。那个屏保简直就是 ASCII 艺术，会跑过 40 种 Demo 效果，看起来完全像 1995 年 Demo 派对的开场。我们把那些效果都拉了进来，也保留了那种终端美学。顺便说，这也是一种和 macOS 或 Windows 完全不同的美学。因为我觉得 Linux 历史上，很多发行版都以为：只要我们做出 Windows 的「我也能」仿品，大家就会爱我们。不，没人想要一份对原本就没那么出色的东西的廉价拷贝。他们想要专门的东西，想要独特的东西。而 Omarchy 的美学完全就是九十年代的 Demo 文化，完完全全是那个，那正是我想要的氛围。

其实就在我们进这次通话之前，我正在做如何在自己的机器上部署本地人工智能。其中一件事是：启动一个本地人工智能模型可能要花一点时间，我不知道，也许几秒，有时甚至几分钟。于是在它加载的时候，我又塞进了另一套 ASCII 效果，就是很酷的字符在屏幕上飘来飘去。它有任何功能吗？没有，绝对没有。它只是为了让你觉得：我正在用一台很酷的电脑。因为那就是九十年代和 Demo 文化给我的感觉。我当时也迷盗版游戏，所有这些盗版游戏都会有一段开场，写着由 Razor 1911 之类的组织破解，文字会旋转着出来，而那天我就会觉得自己酷了一点，只因为亲眼看见了那个。

BBS 也是那样。哪怕你那该死的工作只是在推一张 Excel 表格，至少在那热乎乎的一瞬间，你会觉得自己活着。BBS 文化就是这样。你还记得所有那些协议吗：Xmodem、Ymodem、Zmodem，还有 Kermit。为什么叫 Kermit？没人知道，但听着就很猛。

我在卧室里办过一个精英电子公告板，接了三条线。那时我 14 岁。我可以告诉你，当丹麦电信垄断公司的人来装第三条线，看见这个 14 岁的孩子时，他的反应是：这到底是怎么回事？这肯定非法。而他完全正确。那完全非法，也完全精彩。我至今还能听见 US Robotics 调制解调器的声音，那条 33.6K 接通的声音。那就是这样一种标志性的声音。我们必须再多要一些这样的东西。

电脑就该有一点神秘，该有很多酷，不该被打磨得那么光。再喜欢苹果，我也觉得乔纳森·艾维（Jony Ive）基本上用铝把电脑在那一层上的性格全都抛光掉了。那在一个时期也许是好的，但那个时期结束了。我们要把黑客请回来。
