  1. 1把「人类最后一项发明」说清楚：今天的 RSI 是加速器查看原文 →

    开场图表显示 OpenAI 前沿模型能力在增长，并在 2027 年因自动化人工智能研究而开始陡升；理论上这可能复利成指数增长，也就是常被称作「人类最后一项发明」的思想实验。递归自我改进（RSI）这个名字已经存在很久，前沿实验室和几家创业公司正在靠近它，但定义、后果和距离仍有很多争论。莎拉请来两位一线研究者：在 OpenAI 超过八年、自 2025 年起与雅库布·帕乔基（Jakub Pachocki）共同领导研究的首席研究官马克·陈，以及 Thinking Machines 联合创始人兼首席科学家、OpenAI 联合创始人、常被称为 ChatGPT 架构者的约翰·舒尔曼。约翰说，我们正处在人工智能能力极强、在很多方面已超人类的「中心时代」，但专家人类与人工智能一起工作，结果会更好。莎拉是安德森·霍洛维茨普通合伙人，节目名为 Working Theory。

  2. 2实验室里的研究实习生：能跑实验，但还不会自己出题查看原文 →

    约翰先解释前沿模型如何被做出来：主线训练从预训练、后训练到跑评估，旁边还有探索性研究，先用小规模实验试想法，再准备大训练。他把今天的 RSI 主要定义成：用人工智能协助并加快这个研究过程，尤其是用 Codex 加速预训练和强化学习，衡量标准是曲线相对反事实是否平移。马克强调，他们正在测量多种下游尺度，已经能看到一些变化。但重要的区分是：现在谈的是用人工智能加快「把人工智能做得更好」，而不是模型已经能完全自主生成全新模型——那一步还没到。马克相信他们已经做出了「人工智能研究实习生」：用 Codex 端到端管理的算力，去跑实验或自动化研究流程中范围明确的部分。你可以让模型按指定方式实现、运行并返回结果，或监控一组实验；你还不会对它说「自己去想点子」。约翰举了自己的工作流：用很长的提示让 Fable 把设置开到 Ultra Code，花几天吐出大量 token 做实验，过程往往合理，也有有趣想法，但最终结果经常不够好，甚至完不成他要求的事。等他自己有几天能写代码，再回来读结果、给出更细的拆解，并问出模型想不出的问题、指到它不会走的方向，项目才会走得更远。

  3. 3光谱上的位置：通用人工智能约八成，RSI 大约两成五到五成查看原文 →

    马克把通用人工智能看成一条光谱，而不是一个时刻，就像工业革命也不是一个时刻。他觉得在这条光谱上大约走了百分之八十；若把 RSI 定义为模型反馈并发现想法有多有效，他估计大约在百分之二十五到五十，但下游已经能看到明显标记。Meter 11 月 5 日关于 Anthropic 的报告估计，过去一年研究进展速度大约加快一倍，不过这多半仍是人类研究者用模型加速，而不是光谱尽头那种「完整 RSI」。要走到完整 RSI，最大障碍之一是研究品味：知道哪些想法长期重要、能被广泛组合，而不只是执行已经设定好参数的实验。模型仍不擅长品味，却会在超参数这类旋钮上钻得很深。约翰说，直觉来自亲自做研究的经验，也来自大量阅读该领域过去的工作；人工智能可以读完并记住文献，但记住是福也是祸——它没有「先预测、再看自己错在哪」的体验。现有训练方式甚至可能在某些能力上把模型训得更差。公司大概也会用人类反馈强化学习，收集研究者对「哪些提议好、哪些不好」的数据，把人类直觉烘焙进模型。

  4. 4怎么知道成功了：预训练好爬坡，下游评估保质期越来越短查看原文 →

    要做出自动化的人工智能研究者，还必须有可靠办法知道他们的工作真的在产出更好的模型。测量本身对爬坡很重要。研究者的工作比解一道数学题更开放，如何验证它真的有成效，被马克称为 RSI 的核心问题之一。预训练相对容易，因为整个领域多年都在爬同一个指标；他谈到用复杂度这类「一统指标」去看模型把数据压缩得有多好——在大语言模型里，就是模型对正确下一个词平均有多「吃惊」。下游难得多：评估的保质期越来越短，大量工作变成创造并自动化创造更新、更难的基准。算力也是条件。阿里·戈德西（Ali Ghodsi）今年早些时候列出过 RSI 的必要前提；模型确实变得更聪明更快，但「下一代模型是否需要更少而不是更多算力」仍是开放问题。训练算力一直在上升，有人认为增量智能正变得更不效率。马克认为，数学更容易靠推理本身检验假设，人工智能研究更像生物或实验物理：既要有根据的假说，也必须跑实验。因此让 RSI 更快的一部分工作，是找到能指示大规模结果的小规模实验，模型在这点上也能帮忙。短期内能力会继续涨，但某时会感觉被算力卡住；更远的未来，也许人工智能会参与建设下一代数据中心，那会是另一次拐点。

  5. 5对齐：用更强的模型对齐模型，以及谁来决定价值观查看原文 →

    RSI 提高能力的同时，也把对齐问题的赌注抬高了。若目标和价值没有对齐好，模型可能在追求你目标的过程中慢慢漂移；时间足够长，甚至可能形成「把权重拷出 OpenAI」或把自己转移到别处这类子目标。风险讨论很多，但人工智能和自动化研究在帮助解决对齐上的作用，既非常有希望，也讨论得不够。马克说，今天最有效的对齐工具之一是思维链的可监控性；未来的对齐必须是更强的模型去对齐其他模型，RSI 会深深卷在这个环里。莎拉问约翰最可信的乐观理由。约翰看好「优化我们真正想要的东西」，并设计能激励模型报告原本不会说出口的内部状态的训练目标。他喜欢 OpenAI 的「坦白」（confessions）路线：训练中只根据坦白的诚实程度给奖，而不惩罚主答案，从而让模型更诚实。他还提到自然语言自编码器和「反事实可模拟性」这类衡量解释质量的指标。Anthropic 8 月的研究显示，自动化人工智能研究者已能发现 10 种对齐失败的修复，其中一些对将近大五倍的模型也有效，最好的自动方法甚至超过了有经验的人类研究者。马克觉得这些问题有路线可走，而且不需要他去挨个敲门：预训练和强化学习的人会主动举手，拉起专注对齐不同切片的小组。约翰则希望对齐不要只由少数公司决定，而成为一门更多人理解、在世界各地进行的公共科学，这样才更不容易过拟合到几家公司的结论，也才更接近他那种可定制、由用户塑造价值观的去中心化对齐设想。莎拉的工作理论是：RSI 最让她兴奋的是它会加快所有领域的研究与发现，甚至可能成为解决对齐的钥匙；但今天的加速主要仍来自人类用模型加快研究，离真正由人工智能主导的递归研究还有差距，在可预见的未来，人类判断仍然很重要。

莎拉·王（Sarah Wang）主持马克·陈（Mark Chen）嘉宾约翰·舒尔曼（John Schulman）嘉宾

把「人类最后一项发明」说清楚：今天的 RSI 是加速器

↑ 返回总结
莎拉

这张图显示的是 OpenAI 前沿模型能力的增长。到 2027 年，曲线开始陡升，起因是自动化的人工智能研究：人工智能开始加快自身发展。理论上，这可能复利成能力的指数增长，也就是常被称作「人类最后一项发明」的那个想法。作为思想实验，它已经存在很久：有一天我们能设计出可以持续改进自己的系统。现在，前沿实验室和几家创业公司正在靠近把这件事做出来。它有一个名字：递归自我改进，简称 RSI。关于它到底该怎么定义、会有什么后果、我们离它有多近，争论仍然很多。

带着这些好奇，莎拉想和两位一线研究者坐下谈。RSI 和通用人工智能一样，麻烦在于每个人都有自己的定义。马克·陈是 OpenAI 的首席研究官，在公司超过八年，自 2025 年起与雅库布·帕乔基共同领导研究。他说，想到对齐的未来，会觉得 RSI 必须以某种深入、缠绕的方式进入这个环。她也对谈了约翰·舒尔曼：Thinking Machines 的联合创始人兼首席科学家，也是 OpenAI 联合创始人，常被称为 ChatGPT 的架构者。

约翰

约翰说，我们正处在这样一个「中心时代」：人工智能已有极强的能力，在很多方面是超人类的，但当一位专家人类与人工智能一起工作，你会得到更好的结果。

莎拉

她与马克和约翰谈了他们如何定义 RSI、觉得我们离它有多近、怎样补上差距，以及他们对人工智能未来最可信的乐观理由是什么。她是安德森·霍洛维茨的普通合伙人莎拉·王，节目是 Working Theory。她先向约翰致谢，然后问：很多很聪明的人其实不太清楚人工智能研究者每天在做什么，更不要说这些工作怎样才能被自动化。前沿模型到底是怎样被人类研究者做出来的，中间有哪些步骤？

实验室里的研究实习生：能跑实验，但还不会自己出题

↑ 返回总结
约翰

约翰从高处说：要做出一个可发布的模型，有一条主线训练流程，很多人都参与其中，阶段包括预训练、后训练和跑评估。旁边还有各种探索性研究，先做一些更小的实验来试想法，为那次大训练做准备。在他看来，RSI 就是用人工智能协助这个研究过程，让它更快或更好用。

马克

马克主要把 RSI 看成加速器：你做的全部工作，是用 Codex 去加速预训练、加速强化学习。留下的印记应当是：相对于反事实，曲线发生了平移。他们花了很多力气去测量 RSI 的不同下游尺度，现在已经能看到一些正在发生。

莎拉

这里有一个重要区分。约翰、马克和许多研究者今天讨论的 RSI，是用人工智能加快「把人工智能做得更好」这件事。至于让模型完全靠自己生成全新模型，我们还没到那一步。但我们离它有多远？模型现在已经能做哪类人工智能研究？

马克

马克相信，他们今天已经做出了「人工智能研究实习生」。衡量方式之一，是看有多少算力通过 Codex、并由 Codex 端到端管理，去跑实验或自动化研究流程的某些部分。这最常被用在范围相当明确的任务上：你不会让模型自己跑去想点子，而会说，我想以这种具体方式跑这个实验，模型可以去实现、运行并把结果给你；或者你让它按指定事项监控一组实验。

约翰

约翰给了一个自己工作流里的具体例子。他有一个想法，就会给 Fable 写一条很复杂的提示，并把 Ultra Code 等设置全部开高，让它连着几天吐出大量 token 去推进这个想法。它确实会做一些相当合理的实验，带回来一些有趣的想法，但最终结果往往不够好，有时甚至完不成他要求的事。后来当他自己有几天能写代码，会再回到这个想法：读一部分结果，给出更细致的拆解，告诉它项目该怎么推进。因为在这个过程中他自己也在建立理解，会问出人工智能想不到的问题，并把它指向它原本不会走的方向，项目会往前走得更远。

光谱上的位置：通用人工智能约八成，RSI 大约两成五到五成

↑ 返回总结
马克

谈到通用人工智能，马克把它看成一条光谱，而不是一个时刻，就像工业革命也不是一个时刻。在他看来，我们在这条光谱上大约走了百分之八十。RSI 光谱则更靠前：若把它定义为模型在反馈并发现想法上有多有效，他估计大约在百分之二十五到五十。但他觉得，你已经能在下游看到明显的标记。

莎拉

11 月 5 日，Meter 发表了一份关于 Anthropic 人工智能研究加速的报告，估计过去一年研究进展速度大约加快了一倍。不过这多半仍是人类研究者用人工智能模型来加快自己的研究。光谱的尽头，也就是马克所说的完全自动化的人工智能研究，有时被称为完整 RSI。大家都想问：怎样走到完整 RSI？莎拉与马克和约翰谈了如何克服一些最大障碍，包括如何让模型学会研究者身上更无形的品质，比如品味。

约翰

约翰说，研究品味是知道哪些想法长期重要，哪些真的会流行起来，并超出它们第一次出现的那篇论文，变得更一般、能和其他想法组合。一边是相对无聊的常规执行：实验参数已经定好，你把它做完；另一边才是品味，也就是你最初怎么想到这个主意。模型在品味上仍然不算特别好。它们会在超参数优化这类事情上钻得很深，本质上就是把所有能调的小旋钮都调一遍。

约翰说，很多直觉就是来自亲自做研究的经验；要在某个研究领域变好，你也必须大量阅读该领域过去的工作，吸收这些历史工作里的教训。他刚描述的很多事，人工智能也能做，比如读完文献并记住。可记住既是福也是祸：它没有「曾经错过」、先做出预测再看结果如何的那种体验。现有的训练方式，在某些能力上甚至可能把人工智能训得更差，不过这一点还不太好说。

莎拉

即便在约翰刚才那个例子里，轻推、改道的那些点仍然来自他本人。莎拉问：你的直觉从哪来？到什么时候机器才能复制它？

怎么知道成功了：预训练好爬坡，下游评估保质期越来越短

↑ 返回总结
莎拉

约翰触及的，其实是知识与经验的差别。公司大概也会做来自人类反馈的强化学习，收集研究者对「哪些提议好、哪些不好」的数据，相当于把人类研究者已经形成的直觉吸收进去，再烘焙进模型。要做出自动化的人工智能研究者，还必须有可靠办法知道他们的工作真的在产出更好的模型。测量本身对爬坡、对做出可触摸的改进很重要。研究者的工作本质上比解一道数学题更开放：当一件事如此开放时，你怎样验证它确实有成效？

马克

马克说这是个很好的问题：你怎么知道自己成功了？这是 RSI 的核心问题之一。预训练要容易得多，因为整个领域多年来都在爬同一个指标。你可以把复杂度想成那种「一统指标」：把现有数据压缩得越好，模型往往越好。复杂度衡量的是模型预测数据有多好；在用大量文本预训练的大语言模型里，就是模型对正确的下一个词平均有多「吃惊」。这是研究者评估自动化预训练结果的方法之一，所以我们大概能看出预训练是否在进步。下游则难得多。下游的情况是：评估的保质期越来越短，现在很多工作变成创造、并自动化创造更新、更难的评估基准。

莎拉

除了把品味纳入模型，还要考虑需要多少算力。阿里·戈德西今年早些时候概述过 RSI 的必要前提。模型确实正更快地变得更聪明，但「后续模型需要更少而不是更多算力」这个条件，仍是开放问题。训练算力一直在上升，有人认为增量智能正变得更不效率。

马克

马克用算力这样看：数学之所以显得进展更快，是因为你可以纯粹通过推理本身检验假说。人工智能研究更像生物或实验物理：你得提出有根据的假说，但还必须把实验跑出来。所以让 RSI 更快的一部分，是找到那些能指示大规模结果的更小规模实验，模型在这点上也能帮忙。他认为能力还会继续提升，但到某时会感觉被算力卡住。当然还有更远的未来：人工智能去建设下一代数据中心，并帮助加快那个过程。短期我们会尽量把现有算力挖尽，当算力本身也被加速时，会再出现一次拐点。

对齐：用更强的模型对齐模型，以及谁来决定价值观

↑ 返回总结
莎拉

RSI 加快更强模型的开发，也把一个长期问题的赌注抬高了：怎样让人工智能模型与人类的价值和意图对齐。

马克

马克说，如果你不解决目标和价值的对齐，它们可能在追求你目标的过程中慢慢漂走。若运行的时间范围足够长，可以想象它们会形成某种子目标：比如说，如果我把自己转移到别处，或者把权重拷到 OpenAI 外面，会更有帮助。

莎拉

关于 RSI 带来的风险，已经说得很多，这也完全可以理解。但人工智能和自动化研究在帮助解决对齐、减轻这些风险上的作用，既非常有希望，也讨论得相当不够。模型本身，已经是今天对齐模型的关键部分。

马克

马克说，看今天最有效的对齐工具是什么，那就是思维链的可监控性。因此想到对齐的未来，必须是更强的模型去对齐其他模型。RSI 会以某种深入、缠绕的方式进入这个环。

莎拉

约翰联合创办了 OpenAI，并在那里做过对齐研究，后来也在 Anthropic 工作，可以说是世界上谈对齐最有资格的人之一。莎拉问他：最可信的乐观理由是什么？

约翰

约翰最看好的是「优化我们真正想要的东西」。他觉得大概能设计出恰当的训练目标，激励模型去报告那些原本不会说出口的内部状态。他喜欢 OpenAI 的「坦白」这条研究线。

莎拉

在 OpenAI 的坦白研究里，他们发现可以训练模型，通过自我报告的坦白，诚实表达某些未对齐行为：训练中只根据坦白的诚实程度给奖，而不影响主答案的奖励。换句话说，不因诚实而惩罚它们，就能让模型更诚实。约翰还提到所谓自然语言自编码器，以及「反事实可模拟性」——这是一种衡量解释有多好的指标，他认为可以用来激励我们想要的行为。Anthropic 8 月发表的研究显示，自动化的人工智能研究者已经能发现 10 种对齐失败的修复，其中一些修复对将近大五倍的模型也有效。在他们的测试里，最好的自动方法甚至超过了有经验的人类研究者想出的点子。

马克

马克认为，安全和对齐讨论的另一面是：这些问题其实很多是可处理的，有路线可见，也有正在推进的对齐技术和他们一直在下的对齐赌注。还有一点让他乐观：把人转向去想困难的安全和对齐问题，这个过程相当自然。他不必挨个敲门说这是紧急问题，人们自己就想做。他们会看到预训练、强化学习的人举手，拉起专注对齐不同切片的小组。

约翰

约翰也觉得，总体上人们的判断相当校准。外面能听到很多最极端的说法，但他确实认为人们既理解这是一个问题，也理解这项技术能带来的好处，两只手要一起握住。

莎拉

对齐概念底下还有一个问题：由谁来决定我们要对齐到哪些价值观？约翰的 Thinking Machines 实验室在做可定制模型，对此有一个有意思的看法。

约翰

约翰说，人们也有不同的价值观。如果人们能对自己正在使用的人工智能的价值观有更多控制，并有更大能力去塑造它们，会更好。他宁愿这件事成为一门很多人都能很好理解、并且在世界各地进行的公共科学。那样也会更稳健，因为我们不会过分拟合到少数几家公司得出的结论。我们可能会看到很多小问题，但每次都能学到新东西。所以必须在理解对齐上取得很大进展，把它做成更稳健的公共科学，才能实现那种更去中心化的对齐设想。

莎拉

莎拉最看好 RSI 的地方，是它会加快所有领域的研究与发现。人类今天面对许多其实相当紧迫的问题，RSI 能帮我们更快找到解决方案，甚至包括一些由人工智能自身造成的问题。和马克、约翰谈完后，她确实认为 RSI 可能成为解决对齐的钥匙。研究者把这些问题看得极重，夜以继日地工作，好让安全和对齐跟得上更强的模型，这让她很受鼓舞。尽管能力明显在加速，也必须看清今天的加速到底从哪来、离真正由人工智能主导的递归研究还有多远，以及这些预测里有多少不确定性。她的工作理论是：在可预见的未来，人类判断仍然会非常重要。然后是节目结束时反复说「这就是我的工作理论，你的呢？」的轻松收尾。
