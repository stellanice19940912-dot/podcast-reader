一句话概述

《Latent Space》请到 Clay 人工智能负责人杰夫·巴格（Jeff Barg）。他经前公司 Avenue 被收购加入：Avenue 约2020年由高中朋友共同创办，做过 Y Combinator、拿过 Accel 的融资，客户包括 Ramp、AngelList、Valon、DoorDash；2024年底并入当时约50人、收入约1500万到2000万美元的 Clay，他们是5人团队。Clay 现约600人。对谈从「进入市场工程师」讲到 Claygents 与 Sculptor、为何重建成编码智能体、用约1500美元给4000万家公司做客户适配打分，以及他们明确不希望自有智能体明显强过「Clay 加 Claude Code」——这一使用已经接近五五开。

核心要点

  • 杰夫把 Clay 称为增长用的创意工具：用智能体和数百家数据提供商给公司和联系人名单做资格判断。Clay 七年前从电子表格低代码起步，约三年前在招聘与进入市场之间选择了后者。进入市场工程师被做成品牌，技能叠合智能体工程、数据工程和传统软件工程，客户仍常落在收入运营；成功背景既有传统软件工程师，也有有进取心的收入运营人员。
  • 加入后他们先做出信号产品（监测入职、晋升等市场事件）。当时「人工智能优先」的公司在唯一做智能体的人离职后，一度没有人做人工智能。2023年11月就有过单元格级的联网智能体（Claygents）；Sculptor 于去年9月上线，作为编排器去搭工作流。后来整套架构按编码智能体重写，公开了命令行，跑在云沙箱里。生意自称加入以来约十倍。
  • 资格判断评估已饱和约一年，前沿模型的优势更多留在更高层的编排和「打进特定类型公司」。给4000万家公司每家约1500个token做「是否适合我」的判断，他算下来大约1500美元。合格线索的 enrichment 预算大约每条1到10美元，约到一通电话大约10到100美元。后训练与开源权重模型开始变得可行，目标是保持能力、降成本提速度；他认为推理花费要到1000万到1亿美元量级，节省才对公司有分量。
  • 用户讨厌模型选择器，但他们会保留，同时很快上线名为 Auto 的路由器。自有框架与外部 Claude Code 等框架的使用接近五五开；他们明确不希望自有智能体明显更强，并把 Clay 定位为进入市场的智能体基础设施。技术栈是手写的：BullMQ、Postgres、产品里用 ClickHouse、分析用 Snowflake，不用 Temporal 或 LangGraph。负载很尖（例如对5万家公司各跑一个智能体），还要处理限流、暂停恢复和「吵闹邻居」式的公平问题，推理尚未全面双源。
  • 他们曾把约25%的工程团队投入一个月，做 ChatGPT Apps 第一波商业应用合作，上线前两天被告知无限期推迟，三四天后对方又改主意；他们选择继续做。工作流产品在今年夏天「12周12次发布」中上线，表格对工作流的使用占比上升很快。重构后的 Sculptor 作为第一方智能体已在有限形式上线，他在节目中称大约10天后会带一批新工具公开。询问 YC 有多少公司在用 Clay，智能体约60秒给出答案。
  • 他认为编码智能体仍然不擅长阅读自己的轨迹并判断「错在哪里」，用坏轨迹做持续改进、或让智能体靠改提示词来修表现，目前都不大成立，所以他们仍在手写大量技能。

  1. 1开场：Clay 是什么，以及为何说进入市场是创意工作查看原文 →

    开场集锦里，杰夫抛出几个后文会展开的数字和立场：4000万家公司的数据集上跑「是否适合我」大约1500美元；用户讨厌模型选择器；他们明确不希望自有智能体明显强过 Clay 加 Claude Code；用智能体查 Y Combinator 客户大约60秒；模型仍会用同样输入反复试命令行；ChatGPT Apps 合作把约25%工程团队投入一个月，上线前两天被无限期推迟。主持人介绍杰夫·巴格，他在 Clay 约两年。他把 Clay 称为增长用的创意工具：帮人建公司和联系人名单，再用智能体和数据提供商补上收入、融资、首席执行官、地点等，筛出最好的客户。Clay 七年前从电子表格里的低代码起步，其他人工智能开发者也常把它当作「表格形态」的成功样本。主持人调侃官网更像「建立系统以增加收入」，杰夫则坚持进入市场本身是创造性事业，竞争对手几乎不去这样定位，而这有助于形成一个愿意做很酷实验的社区。大约三年前、在他加入之前，公司在招聘与进入市场之间选择了后者，并把原来很横向的业务收窄到单一画像。

  2. 2进入市场工程师：从收入运营里长出来的新学科查看原文 →

    swyx 把 Clay 与自己做 Latent Space、「人工智能工程师」的路径平行起来，并说明这期有巴兹尔·查塔一起：巴兹尔关注全职当量，Clay 关注进入市场工程师，他关注人工智能工程师。进入市场工程师被做成品牌，背景是2010年代公司靠加人铺管道，而大语言模型和后 ChatGPT 时代让人可以工程化地找客户、做资格判断。杰夫认为它叠合三块：写提示词、理解大语言模型的智能体工程；建名单、转换、enrichment 和视图的数据工程；以及把「联系我们」表单编排成调研再交给销售或外呼的传统软件工程。老名字可能是营销工程师、运营或增长工程师，但增长更偏营销、他们更偏销售；职能仍常落入收入运营，他们也仍卖给这类团队，只是作为学科相当新。成功的人既有从第一性原理转来的传统软件工程师，也有有进取心的收入运营人员。外人常低估其中的数据挖掘和实体解析。名单不只用于潜客开发，ZoomInfo、RocketReach 这类数百亿美元的公司本身就是喂给 Clay 的数据库；Clay 与数百家数据提供商合作，平台刻意做得很通用，权衡是容易出错，但可以做出非常强的系统。

  3. 3卖掉 Avenue，5个人并进50人的 Clay，并先做出信号产品查看原文 →

    杰夫经 Avenue 被收购加入 Clay。Avenue 约2020年初与高中朋友创办，两人中学起就一起做应用，还做过最早一批 iPad 应用；毕业后分别在优步和亚马逊，想把工程上的可观测性带给市场平台运营团队。公司做了约四年半，进过 Y Combinator，拿过 Accel 融资，客户包括 Ramp、AngelList、Valon、DoorDash。2024年底增长不错，也有数据工程公司接洽收购，他们不确定能否走到十亿美元结局，经朋友认识卡里姆和瓦伦后选择并入。当时 Clay 约50人，Avenue 是5人，相当于一天带进公司10%的人。Clay 当时靠产品驱动增长做到约1500万到2000万美元收入，但最大合同很小，还没真正走进中端和企业销售；Avenue 更懂把系统做进 DoorDash 这类规模客户。杰夫更佩服的是 Clay 对「进入市场工程师」单一画像的聚焦，这是 Avenue 没想清楚的。他们加入后先帮助做出信号产品：在静态名单生意之上，监测入职、晋升等市场事件，做成持续运转的收入系统，和技术上跟 Avenue 的市场可观测性很像。难点是客户极度多样，有人想追踪每一个谈过的客户的职业进展、新闻、Gong 通话和网站访客，容易第一天就想「全部响应」然后被淹没。杰夫加入时并不是做人工智能，信号产品更像管道，以前很多人用 Zapier；他把数据放在 Clay 里的好处概括为带状态，例如「同一公司三个人跳到同一家新公司才触发」。

  4. 4人工智能优先却没人做，于是有了 Claygents 和 Sculptor查看原文 →

    加入时工程团队约20人，做联网资格判断和 enrichment 的只有一个大约24岁的同事，后来离职创业，公司变成「人工智能优先却零人做人工智能」。杰夫转过去重建团队和路线图。其实2023年11月、ChatGPT 出现约一年后，Clay 已有可在工作流里搜网页、做结构化抽取、写入单元格的智能体，这至今仍是生意里很大一块，但作为叙事不够激动人心。2025年2月 Claude Code 出来后，他们决定把 Cursor 带给工程的那种迁移带到进入市场。信号之后真正展开的是：Claygents（工作流里爬网、填表的智能体，后来几乎重写技术栈）以及去年9月上线的 Sculptor（再往上的编排器，负责搭表格结构，Claygents 填单元格）。他称加入以来生意约十倍，Claygents 用量比生意增长更快。早期 Sculptor 把访问 Clay 的工具交给循环中的模型，并做提示词和工具定义优化，擅长「加一列」，不擅长「建一套外呼活动、送来10个合格会议」，也缺少销售代表会有的上下文。上线后评估测得不对：有人只想分析自己的表格，企业客户表格里数百万行就会垮掉；当时主要用大语言模型当裁判，看它有没有真的加上那些列。现在对质量的衡量更好，但仍未真正度量下游效果。

  5. 5为编码智能体重建平台，以及后训练要到多大规模才值得查看原文 →

    不用现成方案的三条教训：编码智能体很擅长用 Bash 和 Python 把工具串起来；旧工具表达力太窄，一次难以建多列；原语不够，缺少 CRM 和活动结果。他们做了平台级重建，核心数据上下文层叫 Audiences，把 CRM、Gong 拉进来做实体解析，成为客户和联系人的权威表格，并且是单租户——有缺点，但更简单，定制需求也比想象中更少重复。Clay 自有开箱即用的公司和联系人数据，对外却更强调集成而不是「自有数据」。后训练在他加入后的头18个月并不现实，近几个月在某些方向开始可行：目标是保持能力、降成本、提速度，让模型在自己的工具和输入分布上变好。开源权重模型已相当能用，例如比 Opus 便宜一截的 K3；再往下也许能让更小模型接近 Opus，但不一定是 GLM 5.3 Flash。他警告不要过早追求超越前沿，也认为推理花费要到1000万到1亿美元量级，节省才对公司有分量。

  6. 61500美元打分全世界，以及前沿智能还留在哪些层查看原文 →

    主持人联系到一周前节目谈过的杰文斯悖论：分类变便宜，人们就会用得更多。杰夫说生产里还没用这套做法，但名字很准。今天人们仍会把资格判断限制在比如1万家公司；而他们有4000万家公司的数据，若每家领英约1000个token、理想客户画像约500个token，问「是否适合我」跑遍全世界，他算下来大约1500美元，得到每家公司的适配概率。Clay 里 enrichment 预算差异大，每个合格线索1到10美元是不错的区间，约到一通电话10到100美元也不离谱，取决于客户期望价值。任务型智能体和资格判断的评估已饱和约一年，新模型多在更难的深度研究上更好；越靠近 Sculptor 这类端到端编排，或要创造性地打进非常特定的公司，最好和平均的产出仍可能差10倍、100倍，前沿智能仍然重要。只查最近融资公告，过去一年的模型就够用。模型路由对 Claygents 因此很有帮助。

  7. 7用户讨厌模型选择器，评估则想量到二阶效果查看原文 →

    他们很快会上线模型路由器，名称就叫 Auto，不打算做成 Cognition 那种「Fusion」品牌。用户讨厌选择器并会投诉，但选择器仍会保留，给想自己选的人，尤其是代理机构负责人；Auto 更多给「带着一些进入市场工程想法、其实还是新手、靠口碑找到 Clay」的更广大用户。swyx 用特斯拉自动驾驶作比：大多数人只想把工作做完。任务级路由的例子是：找苹果首席执行官和找一家无名公司的首席执行官不是同一件事，也因此需要信任和用量分析，以免被怀疑乱花 token。Sculptor 之后他们把智能体重写成真正的编码智能体，公开了命令行，跑在云沙箱里。评估仍按用例和轨迹：问第一方数据就该查数据上下文层，并看工作流有没有真的建成。他希望下一步能量到二阶效果，例如外呼名单是否真的得到回复，而不仅仅是工作流建出来。他们不打算做 Sierra 那种完全按结果收费，团队大致均分传统机器学习、应用人工智能和标准软件工程，头衔都是软件工程师。最难招的是有生产级智能体经验的人；Clay 在纽约，这类人不如湾区常见。ChatGPT 至今才四年，人才池本来就有时间限制。

  8. 8不用 Temporal 和 LangGraph：手写栈，以及规模化时什么会坏查看原文 →

    swyx 问工作流、管道和编排是否用 Temporal 或 LangGraph。都不是，智能体持久性很大程度上建在 BullMQ 上，用 JavaScript。杰夫不确定能否在 BullMQ 上再撑住一个十倍。产品里大多数东西手写在 Postgres 上，ClickHouse 用于产品和部分内部场景，Snowflake 做分析，内部数据集曾用 Dagster、正在重做。主持人调侃现代数据栈变难了，并提到前东家 Airbyte；杰夫说刚上线约25到30个新集成，瓶颈不是工程而是合同和质检。他加入时 Claygents 坏掉的很多：缺少可观测性，后来接入 LangSmith 一类工具；推理负载很尖，例如对5万家公司各跑一个智能体，需要限流，以及在提供商宕机或限速时暂停再恢复。他们还没有全面双源，但很在意公平：大客户一次跑100万条 enrichment，不能挤掉只想跑10人工作流的新用户。swyx 总结他在同行那里看到的共同手册：小团队也能做很多、要路由但保留选择器、最终想双源、从闭源走向开源。

  9. 9为什么不希望自己的智能体明显强过 Clay 加 Claude Code查看原文 →

    他们也会在产品里放一个带沙箱、相当不受约束、能用全部 Clay 原语的智能体，但气质是：希望平台对所有智能体都好，无论是自有的还是外部的，并明确不希望自有智能体明显强过「只用 Clay 加 Claude Code」。对外形态是命令行优先，也有 MCP，但团队重心已转到命令行。自有框架与外部 Claude Code 等框架的使用比他预想的更接近五五开。主持人提到有人几乎无法放下 Grok 或 Cursor；杰夫说他们并不必须拥有这块界面，目标是成为进入市场的智能体基础设施。这不是要把进入市场完全自动化，而是把 Claude Code 带给工程的那种迁移带过来：进入市场工程师仍在，只是能做的更多。命令行在很大程度上来自内部需求——很多人就待在 Cursor 里，销售会在 Codex 里做交易准备，进入市场运营团队其实是前工程师在 Clay 上给销售做内部工具。自有框架仍然要做，因为有人就在 Clay 界面里构建，希望智能体也在那里。Sculptor 之后，框架建在开源的 Pi 之上，并用 Vercel AI SDK 接进他们的 JavaScript 栈。

swyx

杰夫

杰夫

杰夫

swyx

哪些方向？

杰夫

对开源权重模型和后训练都成立的一点是：一旦推理量到了一定水平，你可以把能力维持住，同时换小一个量级的模型，把成本和速度做成主要收益。如果你是在该模型的工具集、或你希望它优化的那类输入分布上做后训练，效果会相当好。我们在后训练上还很早，刚开始探索，应该很快会在这个方向上线一些东西。总目标是保持能力不变，降低成本、提高速度。

swyx

杰夫

杰夫

大概就在1000万到1亿美元这个区间，开始算得上「有分量」。

杰夫
