一句话概述

在 AI Engineer CODE 峰会上，刚刚宣布加入 OpenAI、此前在 Anthropic 的塔里克·希希帕（Thariq Shihipar）把人工智能同时说成工业革命和文艺复兴：一边是更便宜、更可规模化、也更容易制造 slop 的软件工厂，一边是把人留在回路里、用「/human」文件夹和决策模型去打磨手感与品味。他回顾自己过去一年的误判——从「只要 bash / React」到模型已经能在 Figma 里按人的方式工作——并怀疑让模型完全无人值守地自我改进，未必是最好的路。

核心要点

  • 他把 2026 年看成软件工厂和工业化的一年，并认为接下来更应是软件的文艺复兴：革命带来效率、可靠性和规模，也制造大量 slop；文艺复兴则让每一档边际质量都值得打磨，而且两者可以放在同一个项目里。
  • 针对氛围编程里「模型擅自做合理假设、自己玩起来才发现不对」的问题，他做了名为 /human 的文件夹：高注释、禁单字母变量、限制行长，文件读起来像规格，却是可执行的真代码，用来亲手调角色技能一类的细节。
  • 他同时订阅 Codex 和 Claude 的 200 美元档，还没碰到上限，并不觉得被 token 或智力卡住，更可能被野心和工作方式卡住；正在做名为 Frontier Lab 的卡牌游戏，并设想用自动测试做平衡报告，但坚持「完美平衡的游戏是无聊的」。
  • 决策模型被他放在「完全硬编码」和「每一步都工具循环推理」之间，并认为现有智能体套件还没把它用好；评估上他提到卡帕西那个经纬度「陆地还是水域」的地图测试，用来看模型是否真的形成了世界知识。
  • 个人软件很难：他做了替代的 macOS Dock，后来自己不用，因为建造时没有真正使用，甚至不一定知道自己想要什么；他也用计算机操作去写 iPhone 快捷指令。
  • 对自动研究与递归自我改进，他问的是一个选择问题：是否真要让模型完全无人值守地改进自己，这甚至可能不是最好的选项。证明能力的方式则从 GitHub 提交图，变成了 AI Engineer 演讲和花掉的 token。

  1. 1冷开场与引言：革命对文艺复兴，以及转投 OpenAI查看原文 →

    冷开场里，塔里克·希希帕（Thariq Shihipar）说自己并不觉得被智力卡住，更可能被野心卡住；他把人工智能同时比作工业革命和文艺复兴，并追问：我们是否真的希望模型完全无人值守地自我改进，这甚至不一定是最好的选择。主持人介绍，这是在最近的 AI Engineer CODE 峰会上录下的系列之一，将在接下来一周陆续放出。嘉宾最近还在 Anthropic，节目录制后（主持人口播为「就在今天」）宣布加入 OpenAI，并做了反响很好的闭幕主题演讲，总框架就是「革命对文艺复兴」。主持人指出，今年最热的词之一是「软件工厂」，但峰会上传出的信息是：也许大家冲向工厂太快了；即便有了工厂，省下的生产力也应拿去耕文艺复兴的那一面。革命让软件更便宜、更可靠、更易规模化，也制造大量 slop（廉价灌水内容）；文艺复兴则让做个人化、把艺术品位做高、把人留在回路里打磨手感变得负担得起。两者可以发生在同一个项目里。核心主张是把反馈回路还给人：与其把人从智能体回路里拿掉、追求熄灯工厂，不如让人容易做出一次性的小工具去试；很多 slop 正是因为人没有真正自己用、自己测。他还有一个名为 /human 的技能。主持人以两个「技术上完美却不用」的例子收束：一款平衡得无可挑剔的游戏，和一个不错的 macOS Dock 应用——因为建造过程中自己从未真正使用。他宣布转投 OpenAI 时，T-Bone 和安德鲁（Andrew）都说，差不多是时候重新发明 Codex 了；主持人强调这是自己的解读，不是代言。

  2. 2过去一年猜对与猜错的地方：从「只要 bash」到能在 Figma 里画界面查看原文 →

    塔里克说闭幕演讲要讲的是「过去一年里自己错在哪里」。他承认也猜对了很多：大约一年前就较早发现 Claude 可以用代码做视频，也较早谈论 HTML，主持人把它概括成「HTML 的非凡效力」。主持人当初第一反应是这只是把 token 用到极致的办法，后来才承认那是更丰富的输出。猜错的例子包括他一度深信「只要 bash 就够了」——赶上命令行浪潮，不要 MCP，只要 CLI，甚至觉得连工具都不需要；他也曾私下觉得 React 会成为终极语言，因为模型只会写 React。他修正说：模型不只是变强，也变「更宽」。能力还在边缘时，它们往往只会用一种方式做事；能力上来之后，你可以让它用计算机操作（computer use）在 Figma 里直接画前端，效果可以同样好。令他意外的是，模型开始按我们习惯的工作方式来做事，而不是只能活在 bash 或 XML 那种「怪异的外星格式」里。下游效应是：人可以理解模型在做什么、并与之共事，未来不必是模型自己空转、堆出无法维护的一团乱麻。

  3. 3「/human」文件夹：把规格写成能玩的真代码查看原文 →

    做游戏时，他发现提示词的麻烦在于：自己其实并不知道游戏里接下来会发生什么。模型会做一些合理假设，等他真去玩，才发现角色在某种情况下会做出自己完全没料到的事，这种「氛围编程」的失控感让他很不喜欢。于是他给自己修了条路：写一套脚本语言，放在一个他称为 slash human、也就是 /human 的文件夹里。这个文件夹的检查规则很不一样——注释密度要高、不许单字母变量、行长也受限——目标是让每个文件读起来像规格，但它们是真正会跑的代码。他可以自己玩、自己调，弄清楚到底在发生什么；例如先让模型做出底层原语，再亲自试「如果这个角色同时打出三个火球会怎样」。主持人补充：模型的默认值往往很强，生成的网站长得差不多，你让它做游戏，默认就会加上按住 Shift 加速之类的设定；默认很好，但也正好提醒人可以做得比默认更多。塔里克把这收回总框架：人工智能既是工业革命也是文艺复兴。工业革命讲效率、可靠性、标准化的质量；文艺复兴则认为每一档边际质量都有用、都值钱。他觉得 2026 年是软件工厂和工业化的一年，接下来会更关于软件的文艺复兴。

  4. 4把软件当手艺：同一个项目里，既能改写成 WebAssembly，也能把控制手感打磨到位查看原文 →

    主持人追问：文艺复兴让人想到意大利艺术史，可他把文艺复兴说成「边际质量提升」，听起来不太像文艺复兴。塔里克解释：以游戏操作方案为例，你可以接受 Claude 的默认方案，也可以反复迭代，手感会明显更好，这种被感知到的质量提升，就是把软件当艺术或内容的一种思路；另一面则是用它发明全新的语言、全新的写软件体验和新的原语，这些同样会被看重。主持人把它概括成：一边是「随便什么都能用 Rust 重写」，另一边是按你想要的小众程度，把边际效用再往上叠一点点。塔里克认为两者可以发生在同一个项目里：等游戏引擎做好，他大概会把引擎写成 WebAssembly（WebAssembly），脚本语言作为更轻的一层挂在上面、用钩子伸进去，平衡甚至可以自动来做。

  5. 5完美平衡的游戏很无聊，以及正在做的卡牌游戏「Frontier Lab」查看原文 →

    谈到自动平衡，塔里克说他会通过自动化测试、也许再加上真实对局，拿到一份关于游戏失衡的报告，Claude 也可能给建议，但他自己也会有观点。他的判断是：一款完美平衡的游戏是无聊的。主持人先抬出《剪刀石头布》作为完美平衡的例子，又用《英雄联盟》（League of Legends）里公认较弱的英雄来追问「失衡有什么意思」。塔里克的回答是：你可以专精一个弱角色并把它练出来；没有角色会永远弱；你要的是高方差——弱但高方差——以及去发现游戏的版本环境（meta），这里必须有真实的「阿尔法」。这些还多半是下一步设想。他随后透露自己在做一款叫 Frontier Lab 的桌游/卡牌游戏：玩家扮演一家前沿实验室，管理资源和科技树去做研究。后段他又回到工作方式：公开模型已经很好，他同时用 Codex 和 Claude 的 200 美元档，还没碰到上限，并不觉得被 token 卡住，甚至不太觉得被智力卡住，更可能被野心卡住；真正的瓶颈是「如何与模型共事」。这正是他做那套脚本语言的原因——做这款游戏时，再酷他也不知道底层在发生什么，而与人工智能共事的体验还有很大改进空间。领域特定知识也在变：他概念上懂可解释性和强化学习，但不一定要会 PyTorch、CUDA 或神经网络架构细节。

  6. 6野心、外行实验，以及还没被用好的决策模型查看原文 →

    正因为不再被领域工具链卡住，他可以去做一些自己并不最专精的强化学习实验，比如改 Kuen（自动字幕对名称的记音，把握偏低），让模型以为埃菲尔铁塔在罗马，再看下游会发生什么。他有一个自己也承认可能很天真的强化学习想法，觉得「好像没人这么做强化学习」，想亲手试；哪怕错了，让有一定能力、但更天真的人去试，对这个领域大概是好事。主持人把探索的关键问成目标函数和数据；除了外界还在猜、没有论文的 RLCD，以及去掉成对偏好、直接做偏好优化的 DPO（他和主持人一度对名称有些含混），还有群体偏好等。塔里克提出一个他认为还没被认真做的方向：图灵测试式的强化学习——「这听起来像不像人」和「你更偏好哪个输出」并不是一回事。还有偏可验证数学的 RLVR。他说归根结底是选对目标函数。把话题收回「决策模型」时，他认为当前的智能体套件（harness）普遍没有用好决策模型：自己开新项目时，常常会先让模型去研究什么是决策模型，并在 Jev 一类工具里写文档，再配上 Jev 或 Luna 决策模型的接口密钥。

  7. 7决策模型：介于完全硬编码和每一步都推理之间查看原文 →

    主持人一开始以为决策模型是在做蒸馏，塔里克纠正：不是蒸馏，而是希望模型知道可以使用这个类。这类接口还太新，模型很难自己用好——即便你明确告诉它，它也可能去做，却不知道该怎么做；你让它「做一个决策模型」，它甚至会反问决策模型是什么，或自己去训练一个小分类器。被问及例子时，他用给游戏写人工智能来说明：一端是完全硬编码的 AI，另一端是每一回合都只跑工具调用循环（还得假设推理循环非常快），决策模型处在中间——你可以预先写出一部分行为，其余交给模型。它的吸引力不只是速度或延迟，也包括置信度和整套体验。后段讨论还落到谁来决定哪些实验能拿到算力：这不是纯技术问题，而是判断和品味，也回到他把人留在回路里的主张。

  8. 8陆地还是水域：一张能看出模型是否「认识地球」的预训练评估查看原文 →

    谈到评估时，他提起安德烈·卡帕西（Andrej Karpathy）展示过的一个漂亮预训练评估：对每个经纬度问模型「这里是陆地还是水域」，再把答案画成地图。结果里，Ovis 5.5 基本上知道地球的整个形状，而 Ovis 4 或 Ovis 4.6 则相当模糊（型号为自动字幕记音，把握中等）。他认为这才是有意思的评估类型：不是只看下游任务分数，而是能看见模型内部是否形成了连贯的世界知识。这类评估和他关心的「决策、判断、什么时候该相信模型」是连在一起的——你得知道模型到底懂了什么，才能决定把哪些环节交给它、哪些必须留在人这边。

  9. 9个人软件：做好了却不用的 Dock，以及用「计算机操作」去写捷径查看原文 →

    塔里克说自己整体在更多实验个人软件。他展示过一个替代的 macOS Dock，把焦点状态组合在一起；但个人软件很难，因为你有一个想法，却很难预先知道它是不是好主意、自己会不会真用。主持人追问：你明明想要、也做出来了，为什么后来不用、又转向了？他的回答接近「我甚至不一定知道自己想要什么」。如果建造过程中自己没有真正用过，技术再完整也可能被放下——这与开场那个「完美却不用」的 Dock 例子相扣。同一段里他还谈到用计算机操作（computer use）去给 iPhone 镜像写快捷指令，因为他懒得去学那些规则；笔记本可以镜像手机，他用捷径去对付一些不再兼容 HomeKit 一类旧智能灯。个人软件的悖论在于：它很能挠到自己的痒，却不一定挠得到别人；有时做得太个人，别人说「能让我试试吗」，答案也许是「大概不行，但代码在这里，告诉它你喜欢什么，它可以重做一份」。而且这类东西往往做起来并不久，还可以随需求改。

  10. 10采用：挠得到自己的软件，未必挠得到别人查看原文 →

    他想做个人软件，也想让别人用上，但这很难——挠自己脑子的东西，不一定挠别人的脑子；对你再显而易见，对别人也可能完全不是。主持人打趣说自己的脑子根本挠不到。塔里克接话：正因为它足够个人，才会出现「这很酷，我能试试吗？」「大概不行」的场面。好在多数个人软件做得快、改得也快。主持人随后把一年收束成「了不起的编程之年」，请他回顾 2026 年的亮点，话题从采用转向更大规模的研究与训练变化。

  11. 11自动研究：要不要让模型完全无人值守地改进自己查看原文 →

    主持人提到近期做了几期围绕递归自我改进（RSI）的节目：模型在改进自己的研究，经历过一轮自动研究（auto research）之后，现在又在优化自己的推理（inference）；他还在等它如何改进预训练和后训练，并觉得可能已有外界并不知道的进展。塔里克回应时把冷开场那句话展开：这其实是一种选择——我们是否希望模型完全无人值守地自我改进？对他来说，这甚至不一定是最好的选项。他承认这些想法还在打磨，有些更像是想以后写成文章的论点。核心仍然是：把人从回路里拿掉、追求彻底的熄灯式自我改进，未必优于把人的判断、品味和选择留在关键节点上，包括谁获得算力、哪类实验值得做。

  12. 12让别人看见的工作：AI Engineer 演讲、沟通，以及工作量证明查看原文 →

    临近结束，谈话转到教育、以及如何在学校之外证明自己。主持人说自己对「义肢式的游戏、义肢式的成就」持支持态度，但不确定这是否真的在为人生做准备。塔里克给的建议很干脆：多用最新工具，多做东西，在学校之外多产出。主持人把话题说得更「元」：自己设计 AI Engineer 时也带一点游戏成分——用 YouTube 播放量做激励、为有播放量的人庆祝，让人在本职工作之外也能有成就。沟通能力的技能天花板很高，可迁移、有需求，应该被展示出来。塔里克说，人大概不会永远在 AI Engineer 上做人工智能演讲：黄仁勋（Jensen Huang）不会来这里演讲，但未来的黄仁勋也许此刻正在这里演讲。两人把这概括成「工作之外的工作量证明（proof of work）」：以前是 GitHub 的提交热力图，现在是 AI Engineer 的演讲，再加上花掉的 token。主持人感谢他抽出时间，期待主题演讲，并祝他玩《魔兽世界》（World of Warcraft）开心。
