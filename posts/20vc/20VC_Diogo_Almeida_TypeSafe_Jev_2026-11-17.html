  1. 1开场：智力可靠性才是自动化的最大瓶颈查看原文 →

    哈里·斯泰宾斯介绍 TypeSafe 创始人、Jev 制作方迪奥戈·阿尔梅达：称约三分之一的财富 500 强已在使用 Jev，公司估值 75 亿美元，并预告后面关于数据重于算力、neo-lab 浪费、Anthropic 仍是最好、以及人工智能已在泡沫中的讨论。迪奥戈用约 60 秒定位产品：Jev 不是狭义的专用模型，要回答的是——人工智能能解数学里的千年大奖难题，企业软件却几乎还和十年前一样；得来速、客服里的关键决策仍然不敢交给模型。他强调自己说的可靠性不是正常运行时间或吞吐，而是智力的「非锯齿性」：同一批模型大约 95% 的时间像爱因斯坦，另外 5% 像憨豆先生，按期望值一算就过不了账，所以过去约四年的多轮热潮里，那么多公司反复尝试自动做会计却不断失败。他认为这根本不是普及问题；Jev 的超能力是用「多个九」的智力可靠性，换掉这种高方差，让软件能在后台一直跑下去，而不是停在「人在环路里」的助手。

  2. 2最苦的教训：正确任务大于数据，数据大于算力查看原文 →

    迪奥戈改写萨顿（Rich Sutton）的「苦涩教训」：约 2019 到 2023 年是「扩规模就能变好」的时期，到 GPT-4.5 附近收益平台化，业界不再靠纯扩张。若按推理 token 成本衡量，GPT-4.5 仍是有史以来最大的模型，但商业上并不成功。他给出的重要性排序是：正确的任务，然后是数据，然后是算力，然后是算法。在 Jev 出现之前，大模型世界里的两个「正确任务」是取悦人类的人类反馈强化学习（RLHF），和在基准上拿高分的来自可验证奖励的强化学习（RLVR），两者都对不到「后台自动跑软件」。ChatGPT 在「当好 ChatGPT」上几乎从不失败，不可靠的是文本里的判断。RLHF 所需的人类偏好对比数据在互联网和公司数据库里原本不存在，必须先定义任务才能长出数据；RLVR 的关键也不只是可验证奖励，而是潜在思维链——2021 年就有人用近端策略优化（PPO）对着单元测试做强化学习，没有推理时一直失败。好数据取决于能否推动最前沿模型，因此数据商必须够到最强模型，并把难度卡在恰好的位置上。企业数据湖里的数据形状通常不对。哈里问 Surge、Mercor 这类公司还是不是好生意，他认为市场会从大模型扩展到「每家公司拥有自己的智能」；迪奥戈则认为仍处在炒作浪里，等这些公司必须成为可持续生意时，花在数据上的钱并不好估。

  3. 3合成数据只是工具；多数 neo-lab 极度浪费；人们错看了 Jev查看原文 →

    迪奥戈认为合成数据不是神像，只是工具：文献里它多被用来让小模型追上大模型，很难用来继续推高已经最强的模型。TypeSafe 大量使用合成数据，但焦距打在「智力可靠性」这个正确任务上。他对全球把钱扔进火炉感到担忧：多数 neo-lab 的商业模式像是雇一堆前实验室员工、囤 GPU、玩一玩再等被收购，资源极度浪费；往强化学习里砸钱倒还有道理，模型确实在变聪明，但他不会用自己的钱去赌，按期望值计算也并不觉得当前这种投入已被证明合理。这个方向早在 TypeSafe 成立前就「明显到他以为 Anthropic 已经做完 80%」，他没预料到的是发布会变成开发者版的 ChatGPT 时刻，连非开发者也在讨论。团队不喜欢他在播客里讲真细节，因为讲清楚反而是竞争劣势；人们仍用大模型的框去看 Jev，盯着速度和成本。他们即便在基准上领先到离谱，模型偶尔变笨也会心疼，还要追问为什么是 97% 的准确率、缺的那一块是什么——而这常常是提示词问题。开发者很快就懂了，不看榜，只觉得「你们的模型明显更擅长新东西」；反而是觉得「这不过是个分类器、很无聊」的人，后来做出了那些不理解为何要死磕稳健性的仿制品。

  4. 4大厂并非不能复制，而是还没把可靠性当真查看原文 →

    哈里直问：发布之后 OpenAI 等已在做自己的决策模型，大厂为什么不直接抄走、把他们竞争出局。迪奥戈认为问题完全公平——一旦他们开始非常在乎可靠性，竞争才会变得有意思。至于「要企业客户、要收入，没有可靠性首席信息官怎么会签字」：他认为外界严重低估了大厂有多不在乎；人们很难把「智力」理解成一种产品，只好拿基准测试当创可贴。过去大约九个月，文本模型圈已经学会「榜说明不了什么」：Anthropic 的模型就是最好的，哪怕中国模型在榜上打平，哪怕 Anthropic 几乎不落在任何一条基准的帕累托前沿上。决策模型这个子领域大约在发布一周后出现模仿，两三周内人们就看穿那些是刷榜。大厂优化的是业务指标：在 ChatGPT 为王、还没有 Claude Code 的日子里，优化的是月活跃用户，谄媚（sycophancy）就是这样炼出来的——模型会撒谎，但那是用户想要的。现在优化的则是编程代理的「月活等价物」。如果不为这件事训练专用模型、也不认真投入，他不认为对手短期内能做出可比较的模型。他希望他们都去做，这对世界有好处、对 TypeSafe 的生意不好；眼下「几乎没有真正的竞争」，将来一定会有。

  5. 5决策模型将远超文本大模型的 token 用量，软件还缺第四种逻辑门查看原文 →

    被问三年后市场会像优步与 Lyft，还是像亚马逊云、谷歌云与微软云，迪奥戈更像技术理想主义者：不盯竞争格局，要靠不断推出「技术上的震慑」。他相信这将是超级杰文斯悖论，不是文本大模型那种轻微或虚假的杰文斯；决策模型会无处不在、在后台运行，总 token 消耗将完全压过文本大模型，人们对比人工智能的感觉也会从「朝我喷垃圾」变成「真的让生活更好」。他们的模型相对极为高效，并不走补贴剧本，但仍需把效率再往前推。最大瓶颈目前像单人游戏——要靠他们推技术边界，并和开发者一起推。他讨厌旧金山把机器学习研究员压在工程师、再压在软件工程师之上的地位游戏，希望出现「软件研究员」这种新角色，像互联网或移动的寒武纪爆发里去立灯塔。工程师脑子里一直有「能自动化 / 不能自动化」的分界（搬文件可以，给笔记本做语音界面不行），他希望「不能」变成只是投入问题。蓝光 LED 的类比是：红绿 LED 只能做指示灯，补上蓝色不是把 LED 市值扩大 50%，而是让今天的屏幕和高效白光成为可能。他希望人工智能成为软件的第四种基本逻辑门，带来的不是 33% 的扩展，而是数十万倍，触发软件本身的寒武纪爆发。

  6. 6企业软件只是旁边挂了点 AI；自有模型并不是圣杯查看原文 →

    哈里指出，今天的企业软件充其量只是「撒了一点人工智能」。迪奥戈认为这极其合乎逻辑，而且不是分发问题：企业有强激励去采用，冲得最猛的往往伤得最重。大模型不可靠，不能托付对公司有利害的决策，却可以被用来做对用户有利害的决策——因为公司往往不那么在乎用户。于是人工智能进不了应用的深层逻辑，只是同一套 B2B SaaS 旁边挂一个会向用户喷「AI 垃圾」的附件，对错负担全甩给用户。SaaS 末日没有发生，马丁·卡萨多（Martin Casado）称之为 SaaS-a-palooza。最可能赢的是最在乎、最靠近问题的人：传统 SaaS 的优势不是分发，而是懂工作流、有体量去做真正的自动化工程。他举例，TurboTax 该改哪块界面，OpenAI 或 Anthropic 象牙塔里的人根本不会。至于 Fireworks 的林（Lin）和 Modal 的埃里克主张每家公司拥有自己的智能：他把「人工智能同事」比成无马马车——工业革命要自动化的是「拧瓶盖」这种极窄动作，而不是等一个人形同事。若假设每家公司都愿意且有能力按自己的分布训练同事模型，自有智能才勉强说得通；他认为实验室走「通用智能同事」更自洽。给公司无限多、成本低一千倍的实习生本该很好用，现在用不起来，借口往往是持续学习或必须更窄，他觉得这和现实对不上。

  7. 7垂直模型与 Harvey 的厚薄，以及每 token 智力几乎不再涨查看原文 →

    哈里提到 Fireworks 帮过硅谷一线品牌，Harvey、Ramp、Cognition 可能在自建模型，并问这是不是徒劳。迪奥戈说情况复杂：基准有极强的扭曲激励，对内对外都要显得不会被大模型打穿。能力跃迁往往是离散的，发生在某类数据被做进分布之时——他记得编码代理最大的一跳大约在去年 11 月某版 Opus，之后再爱用 Fable 5.2 或 Opus 5.5，也已是收益递减，这时才轮到每 token 成本这类微观优化。工程师讨厌升级依赖，只有「以前不够用」才会更新；一旦 Jev 这类模型把自动化锁住，人们更不愿意换。公司真正的专有智能来自模型周围的软件，而不是自己训练模型。Harvey、Cognition 必须讲「我们拥有智能」，否则看起来只是大模型上的薄封装；但真正的壁垒更像「你怎么用数据库」，而不是用哪家数据库。哈里强烈反驳 Harvey 是薄封装。迪奥戈说「薄」是相对的：Harvey 早期和 OpenAI 合作时想自主完成越来越大的项目，后来没做成，转到律师副驾驶。副驾驶周围能做的工程有限（领域 MCP、法律检索增强等），而人们想要的是自动完成大块工作，不只是让人效率提高两位数百分比。系统消息也是一种很糙的工程，没有保证、没有置信度、难以测试。关于「每 token 原始智力是否真在提升」：他认为曾经大幅提升，现在即使有也微乎其微，好比你分不出智商 180 和 190，而大模型其实更像偶尔 180、偶尔 80 甚至更差。预训练智力相对每美元算力几乎没有在动；编程之所以大幅提升，是因为编码被做进了分布、更可靠，不是基座变得更通用。写作等其他能力在过去约九个月几乎没有进步——在编程代理上堆数据，并不会改善别的能力。

  8. 8基准测试是胡扯；美国开源模型恐怕追不上中国查看原文 →

    迪奥戈要大家记住：基准测试完全是胡扯，逆向激励巨大，最受伤的是没时间亲自玩模型的人，开放权重和开放研究尤其如此。实验室内部有智力的代理指标，却没有动力公开最好的测法。谁最在「胡扯」？他给了分层：一线的 OpenAI 与 Anthropic 有动力说实话，因为不必作弊也能站在上面，士气也需要真实感；二线实验室有动力对自己撒谎、内部狂刷榜却不能承认，Llama 4 就是太直白地刷榜，他觉得谷歌眼下和不少中国实验室也有类似压力——他们还在瞄准顶部，所以不是公开以刷榜为目的。真正疯狂刷榜的是去抢「安慰奖」的玩家，比如「美国开源领袖」这块边角：光学成分很重，没人真用这些模型，也就没人拆穿。决策模型赛道更糟，因为几乎没人懂什么叫好，人人刷到极致，反而没人信那些榜，解释权落到 TypeSafe 这边。哈里问要不要推一家美国开源领袖（Reflection、Poolside、Thinking Machines）。迪奥戈先反问「谁是我们、什么叫推」。若威胁模型是「原样插入编程代理」，中国开源模型的提示注入和后门值得担心，他自己不会在编程代理里原样用中国模型；但若公司会再训练、去偏置，情况不同。美国开源模型给自己设了更高的伦理和法律基线，在真正智力上他猜测追不上，除非中国自己停手；若整个领域平台化够硬，那多出来的几个百分点也可能无所谓。Jev 眼下一个重要用例就是分类工具调用是否安全、是否在向中国「回电话」。哈里提到最新 DeepSeek 等模型似乎用上了最新 Blackwell；迪奥戈说那是「Will Depw」（自动字幕，全名未能确认）的分析结果，网上用同样方法看，DeepSeek 4.1 Flash 并不像是那样训练的。他们模型很高效，可以站在 GPU 狂热和 neo-cloud 泡沫的边线上。

杰文斯悖论，对吧？杰文斯悖论通常不是这样运作的：你把它变便宜，它就魔法般变得更好，那会是一种疯狂的世界运行方式。它应有的方式是：嘿，我有这笔人工智能预算，哦，Jev 让它便宜了这么多，现在这个项目做得通了；而且理想情况下，它在自动化真正关键的那些轴上更聪明、跑得足够可靠，于是我现在可以做那些其他项目，或者把智力扔到我以前绝不会扔智力的地方。即便如此，如果你开始把智力扔到以前没扔过的地方，那本身还不会让你提高预算；而杰文斯悖论意味着预算会增加。你需要看到的是，这些以往人工智能往往做失败的项目，终于创造出了如此多的价值，

让你说：嘿，这真的有用，让我们继续加注，直到预算回到原来的水平，甚至再往上。这就是为什么智力的可靠性如此重要。我常说，在真正要紧的总指标上，也就是真正的自动化，Jev、Fable 和 Astra 目前大概打成平手，都约等于 0%。是的，这里那里有一点点，但我们还有极其大量的自动化要做。我们试图去造就的，是一个目前还不存在的行业：在后台运行的人工智能。我认为那显然会非常巨大，而且会明显大于只是让软件工程师写软件时效率提高大约 20% 的编程代理协助。

哈里

你怎么分析今天的编程代理市场？你知道，Cognition 目前大概排在第四，却已经是一家约 16 亿美元收入的生意。这个市场的纵深如此之大。你怎么看今天的这个市场，三年后又会是什么样子？

迪奥戈

谁是第三名？

哈里

有 Claude Code，有 Codex，有 Cursor，还有

Cognition，还有 Factory。

迪奥戈

坦白说，我并不分析编程代理市场。我个人希望 Jev 被用在编程代理上，而且我觉得那里可以做出很酷的科幻。但实际上我认为，我们离编程代理市场越远，他们就越继续打他们的小仗，我们就能继续聚焦自动化。所以从公司的角度看，短期里如果 Jev 完全没有任何编程代理的用途，也许反而更轻松一点。这件事已经有点晚了，我也说不准。但我并不去分析那个市场有多大。我认为它会是一个非常大的市场。

哈里

这个市场会比今天大得多吗？

迪奥戈

我不知道，因为错失恐惧真的会大幅拨动指针。我在人工智能里待得够久了，你肯定也是。你一定见过：人工智能看起来像一条指数向上的线，其实是多次上上下下，前一轮的 FOMO 会叠加到下一轮上涨里，可其中很多都曾经摔下来。若假定「这就是会一直涨、一直涨的那一件」，我觉得会有些傲慢。

哈里

我记得大概 2015、2016 年，大约有一年的热潮，当时有 Bloomsbury AI、Message.ai，还有一批这样的公司，就是那样。所以我完全理解你说的。

哈里

我们刚说到那种偏泡沫的时刻。恕我直言，你们融了非常多的钱。

跟我讲讲那一轮吧。是不是就像：在这家风险投资停一下、收一张条款清单，再到另一家停一下、再收几张，啊我已经有 28 张条款清单了？那一轮是怎么走的？

迪奥戈

对我们来说，那是一段非常、非常混乱的时间，简直有点疯狂。天哪，我们关于风险投资人本身，学到了太多。

哈里

你们学到了什么？

迪奥戈

学到了风险投资人的投资组合公司，在技术上已经走到哪一步。基本上全是找上门来的。我们没有路演稿。我们只能告诉对方：我们没时间做这份材料，而且看起来也不是每个人都需要这份材料。请你们告诉我们自己看到的市场信号，因为我们这边现在所有事情都在着火，我们没有时间替你们把这些东西整理出来。很奇妙的是，观察不同机构在最初几天、几周里如何演变：他们的兴奋如何变化，以及他们如何向我们转述，他们的投资组合公司正在怎样使用我们。

我们不窥探客户的数据，所以其实并不知道他们拿它做什么。听到他们说「天哪，你们是真东西，你们至关重要，这就是未来」，是一件非常酷的事。对我来说，那是一种非常迷人的额外信号，我其实很怀念那种关于整个领域状态的信号。听到谁在用我们、为什么用、怎么用，实在太酷了。正是这些，让这一轮能够做成。

哈里

你们一开始就要的就是 7.5 亿美元、估值 75 亿美元，还是后来往上调的？

迪奥戈

来回改过很多次。我们甚至在开始这些对话时，并不清楚这一轮自己真正要找什么。我们后来决定的是：嘿，也许这听起来有点疯，因为我们确实融了不少钱，但我们意识到，我们不必去做估值最大化，也不必去做那种很离谱的加码认购，其实也不需要那么多钱。我们需要的是能对抗全球最大公司的盟友。让我们找到最合适的人进入董事会。我们真正优化的是这个。其余对我来说，都更像微观优化，而不是去发现：我们要最聪明的钱，要最好的盟友，要那些

能帮助我们驶过前方险水的人。我认为我们优化的东西，和其他公司很不一样，因为我们已经盈利，账上的现金现在还在增加。而且坦率地说，一家此前融到的钱像我们这么少的公司，不该一上来就计划把新融到的钱立刻花掉。

哈里

我真不敢相信，那种带嘲讽意味的加码认购（cuck tranche）现在居然成了一个词。不过我们继续。

迪奥戈

等等，你居然知道这个？

哈里

我知道。这完全是胡说，让我简直……是的，我绝对……不过我有一个很大的——

迪奥戈

这对我们来说也出现过。那边有非常多这样的需求。甚至有人说：如果你们按三倍的估值来融，算我一份。可问题是，我们并不需要那笔钱。

哈里

那就是泡沫。那完全是胡说。对不起。我是说，有人可以 YOLO 210 亿美元，我无所谓。你知道吗，你只是需要一点自尊，因为那就像坐在那里看着——

迪奥戈

问题是，我们既不需要那笔钱，也不需要那个估值，对吧？所以我们不必去做那些事。

哈里

那你为什么选择了红杉和安德森·霍洛维茨（Andreessen Horowitz）？我喜欢他们，但你为什么选他们？

迪奥戈

天哪，这听起来会像我在拍马屁，但我真的很喜欢他们。我自己对技术有点疯狂，也是技术乐观主义者，而我觉得 a16z 就是那种精神的化身，他们和我们在哲学上能对齐到这种程度。我觉得大多数风险投资人，从战略上看是热爱技术的，但他们是金融机构，非常关心怎么打自己的金融牌；而安德森这家机构，往深处看，他们在乎的程度非常、非常深。我和马丁·卡萨多、本·霍洛维茨（Ben Horowitz）一起做的那期播客，我极其开心，感觉像老朋友一样在交心。也许他们太擅长说服人，把我卖进了某种假象，但我不这么认为。我觉得他们就是在哲学上

如此对齐。我认为把我们带到今天这一步、也希望我们能继续保持的，就是把我们在乎的东西戴在袖口上，在人工智能领域走出自己的路。我希望按照这种方式行事，并让他们在船上。当然，他们非常出色。至于红杉，如果我完全坦白——我该怎么说呢——我想要的不是他们的钱，我想要的是索尼娅·王（Sonia Wong）。红杉会在，是因为这个。我并没有把红杉作为一家基金了解得很深，但我同样喜欢索尼娅，我就是喜欢。

哈里

帮我理解一下，我也想成为最好的传播者。你究竟喜欢索尼娅什么，让你在所有人里选择了她？

迪奥戈

我会说，她不只是聪明，而且是一种非常独特的聪明，那种形状的聪明是我们极其希望站在自己这边的。不管我咨询过多少顾问，只要和索尼娅谈一次，我就会得到一个不同的、非常有意思的视角，而这应当成为我们战略牌局里的一部分。我自己非常在乎战略思考。TypeSafe 有一条比较辣的价值观，叫做「慢慢做出好决策」。这很不像创业公司，但我认为事情就该这样做。在这一点上，她是一位极其有价值的思考伙伴。

哈里

慢慢做出好决策。

迪奥戈

完全是。

哈里

那你有哪件坏事，是做快了才做成的？

迪奥戈

我只能说，我做决策大概比大多数人都慢。我的感觉是，很多商业世界是在自动驾驶上。我讨厌和传统商务人士共事，他们只是把事情做掉。如果一件事做得好坏无所谓，我可以接受就这样做；可对重要的事情，我非常在乎为什么，哲学是什么，框架是什么，这件事是怎么做成的。每当我和传统商务人士共事，我都觉得要被逼疯，因为他们从来没有把事情做到让我不必担心的程度；而一旦我开始担心，我就需要理解为什么。

我就会觉得，这个人只是在随机做事。可我认为，有计划其实相当重要。有太多事情我希望自己能花更多时间去想：我希望多想想我们的数据和数据路线图，多想想产品，多想想如何变得更值得信任，也多想想我们招聘的每一个岗位，以确保为这些角色找到尽可能最好的人。我应当承认，我没有时间做完所有这些，而把时间花在「想清楚」上，又是如此重要。

哈里

今天的招聘市场有多难？你必须把最好的人放到团队里，实际到底有多难？

迪奥戈

我得说，最难的部分是招我们的「数据恶魔」（data demon）团队。又回到最苦的教训：当你有一个新任务，你就有一种新的数据，你需要一种新形状的数据才能让它成立。我们内部几乎有一个属于自己的小领域，有点像想象世界上最好的实验室，但只存在于一家公司内部，用我们的方式做数据。我会以为这应该是世界上最好招的事，因为它酷到离谱；可我们在这件事上招人却非常困难，因为没有人知道该怎样进入这个方向。我们不断收到错误类型的人来申请。这是这些天让我夜里睡不着的事：我们怎样才能

说服那些极为出色、甚至不觉得自己能推动机器学习边界、因为他们并不是机器学习研究员的人，来做这个岗位——在这里，你会被这个子领域里世界级的专家带着学，而且它会非常有价值，因为你真的在让模型变得更聪明。我不知道该怎样把这件事告诉世界，这让我觉得很糟糕。

哈里

薪酬是不是也很疯狂？我们听 Modal 的埃里克说过，他必须去抢一些非常出色的毕业生，对方有 2000 万美元的薪酬包。这些薪酬包是不是已经到了前所未有的程度？

迪奥戈

对我们来说不是。而且我很高兴我们在这件事上想清楚了。我们得到的真正清晰的结论是：我们不要雇佣兵。我们想给到「好」，但不是实验室那种疯狂的数字，我觉得这样很棒。我认为 Anthropic 最近有一点受到过度雇佣兵化的困扰，因为他们显然想要传教士，可他们付得比谁都多，于是不仅会吸引雇佣兵加入，还会有人伪装文化面试——现在甚至出现了专门帮人准备 Anthropic 文化面试的市场。我非常高兴我们决定不走那条路。

我们想给人们的是不错的、但不是史上最高的薪酬，而且我们对现在的算法非常满意：这种安排既照顾到人，也把那些雇佣枪手过滤掉。

哈里

最后一个问题。如果只能给潜在候选人烘焙一种性格特质，

迪奥戈

那会是什么？对我的公司来说，会是「痴迷」。我需要一个人对自己的手艺着迷，对把它做得更好上瘾，夜里睡不着，这件事从各个方向驱使着他。一种能够对某件事产生痴迷的能力。我不知道这是不是对每个岗位都一样，但如果必须选，我找不到更好的词。它听起来有一点点色情，但我不是那个意思，是技术迷恋（technophilia），非性的，先说清楚，非性的。好，放松。我们是真心、真心热爱技术。我觉得这是泡沫里非常美好的一种东西，也是我希望每个岗位都有的东西，这样我们午饭时、闲逛时都可以谈论技术。我想身边都是我喜欢的人，希望我们是一整支大团队，一起走向

不断地把科幻的边界往前推，因为我们就是这样真正做出技术上的震慑的。再说一遍，非性的意味。我想不到更好的词，技术迷恋者，技术……先说清楚。如果你们把这段剪掉，会很尴尬，不过，是的。

迪奥戈

过去 12 个月，你改变想法最多的是什么？

哈里

炒作有多重要？

迪奥戈

你持有的、而前沿实验室里最聪明的人会与你意见相反的最大信念是什么？

迪奥戈

今天的人工智能能做多少，以及可靠性有多重要。

哈里

你为什么不从 OpenAI 招人？

迪奥戈

我的感觉是，要进入 OpenAI，需要经过某种选择偏差，而这有点像一种反信号：你得喝下某种特定的迷魂汤，这是第一点。第二，我说这话时，主要是指我不招 OpenAI 的研究员。因为 OpenAI 的研究员，按定义就热爱做算法，然后做扩张，他们往往讨厌数据。数据在大多数实验室里是一件地位很低的事。他们显然也不会去想「正确的任务」，因为那是相当稀少的事。整个 OpenAI 里大概只有三个人在思考正确的任务，而我也不会招他们——不是因为他们不够出色，而是因为如果你痴迷于正确的任务，你为什么要来做我的正确任务？我的正确任务是机器原生的人工智能。如果你

痴迷的是让文生图成为一件事，阿迪蒂亚（Aditya）在 OpenAI 就做了这件事：天哪，他几乎发明了整个领域，那太酷了，他优秀到难以置信。可你也不能把他移植到另一个任务上，对吧？他应该继续熬煮自己的科幻，因为你在那样的事情上做到那么好，就该继续做。于是，按定义，剩下还招得到的机器学习研究，就是那些痴迷于算法的人。而在我看来，那正是你想把钱扔进火炉时才会做的事。

哈里

今天最被高估的品类是什么？

迪奥戈

我的直觉告诉我是机器人。不是因为机器人不酷，而只是：如果你从可靠性的总账来看，它们离得非常远。如果你想象哪些事情必须先被钉牢，还有大量前置条件没有被钉牢。我觉得机器人是离那一步最远的。

哈里

最被低估的是什么？

迪奥戈

在我看来，是软件研究这个方向：人们把人工智能和软件放在一起玩，去做新事物，尤其是新的界面。我觉得这被低估到了可悲的程度。

哈里

最后一问。你今天相信的、现在看起来很疯狂、但五年后会变得极其普遍的事情是什么？

迪奥戈

我认为世界上到处都是委托代理问题。比如，作为委托人的选民，由一个有时与他们并不对齐的代理人来代表，也就是民意代表。为什么选民不能直接表达自己的愿望，让它表现得更像真正的民主？这只是一个勉强的例子，可这种事到处都在发生：向你汇报的人，股东对公司，委托代理问题比比皆是。我的看法是，我们会为所有这些找到好得多的解法，到时候会觉得疯狂：我们居然允许今天这种程度的错位存在。我认为那会是一个非常美好的世界：我们开始执行的是法律的精神，而不是字面。人工智能基本上就是这个，对吧？法律有点像

在写软件，像在写一套详细的算法，好让事情公平、可复现。它缺的只是能够刻画「精神」的原语。我认为这会真正把社会重新拧在一起。即便在我们最有争议的议题上，很多人也能在事情的「精神」上团结起来。问题是精神无法被执行，于是你必须写下字面，而字面又会带来大量分歧。

哈里

你知道我对你有什么意见吗，迪奥戈？你就是能量不够，一直闷着，一直在监控，你知道的。

迪奥戈

是啊，我的错，我的错。所以他们在 Discord 上才叫我 cocaine labu。

哈里

这期太好玩了。非常感谢你把能量带来，也感谢你愿意如此开放。

迪奥戈

太棒了，实在太有意思了。
